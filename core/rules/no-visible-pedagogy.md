# 页面和音频全面杜绝显性教育痕迹（No Visible Pedagogy）

课表（如思维课表 `thinking-plan.md`）和 params 里的 `skill`、`focus` 只给编辑部内部排题与编排使用。

### 红线要求

- **全面杜绝教育说教痕迹**：
  页面内容与音频讲读中**严禁出现任何教育化、训诫化、测试化痕迹**。严禁出现“练思维”、“学知识”、“考考你”、“今天学到了什么”、“思维本领”、“训练”、“技能”、“考点”、“这道题考的是……”、“动脑时间”、“小朋友想一想”、“测试一下你的观察力”等字眼或教师口吻。
- **纯粹的内容与故事体验**：
  孩子拿到的就是一本好玩的杂志，听到的是几个好朋友陪自己一起翻书聊天的温暖节目。思维逻辑藏在悬念、选项对比、线索链与日常发现里，科学原理藏在好玩的问题和生活类比里，绝不需要也不允许对孩子点破“这是在教你”。
- **音频里的伙伴对话**：
  四位小伙伴之间的提问只能是自然的好奇、生活直觉上的疑惑或轻松好玩的小猜测（如“咦，真的假的呀？”“我猜是这样，你觉得呢？”），严禁任何角色扮演“出题老师”考其他角色或考听众。
- **教学意图完全隐蔽**：
  所有思维方法引导、解析与给家长的聊法只写进后台文件与 `_answers`。家长讲读稿可以供家长参考，孩子看到的页面和听到的音频讲读里严禁留下任何痕迹。

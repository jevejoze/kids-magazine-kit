# 英文档位

用到英文的栏目（波波鼠台词、新闻关键词、连载金句、单词屋、英文三关）都按这一份挑难度。

记在 `profile.md`。当前起点是 L2。档位决定波波鼠台词、新闻关键词、连载金句挑多难的英文；做单词屋、英文三关时也按档位出题。
- **L1**（Movers）：一般过去时、比较级；句子 ≤ 9 个词
- **L2**（Flyers）：完整的小段落，可以用 because / when / if 从句；单词屋每期 1 个新词
- **L3**（KET / A2）：120 词左右的短文，现在完成时、情态动词；可以出简单的阅读理解

调整规则（做英文三关时）：孩子连续 3 期轻松答对 ⭐⭐ 以上就升一档；连续卡在 ⭐ 就降一档。暂停英文三关时，档位按家长观察调整。

# 内容红线

每张任务单都自带这一份，栏目声明里去不掉。

- 新闻和知识只选正向、好奇心向的；不写灾难、暴力、恐怖、政治、外貌评价
- 科学事实写之前先核实，不确定的就换题
- 捣蛋鬼（cast 的 trickster 槽位，默认是捣蛋浣熊）可以调皮，但不做真正的坏事；冲突最后要和好
- 不出现真实 IP 角色名字和形象，只用本编辑部角色。例外：经典连载里公版书的角色和公版原版插画可以用；音乐盒、放映室里的作品和角色只提名字、配官方剧照或海报，编辑部不画它们；动手做的 3D 模型只选自由授权（CC）的原创模型，不打印真实 IP 角色
- 经典连载用自己的话从原著改写，不照抄现有中文译本；歌词、台词只介绍，不转载

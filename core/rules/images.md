# 图片与新闻

所有用到照片的栏目（封面、环球小报、怪物档案、经典连载、真的假的和周末思辨的配图）都守这一份。

- **封面照片**：先在 Wikimedia Commons、NASA 等自由授权图库找；Commons API 要带 User-Agent，被限流就等几秒重试。优先选能证明"反直觉"的照片（拍摄时间、地点本身就是证据），用 Commons 页面上的拍摄时间核实，`cover.stamp` 只写核实过的信息
- **新闻来源**：News for Kids、Science News Explores、DOGOnews、Time for Kids、BBC Newsround、NASA。每条新闻至少用 1 个独立来源交叉核实，来源链接写进 `_answers.news_sources`。按内容红线过滤，政治、选举、抗议、灾难类一律跳过
- **新闻照片要一眼看懂**：照片拍到的必须是新闻里真实的那个东西（那只动物、那枚火箭、那座建筑），孩子不读字也能说出"这是什么"。钟、标志、图表、会议合影这类抽象或象征的图不用；没有这样的照片就换一条新闻
- **新闻配图**：新闻原图有版权。杂志只在自己家里看、数据目录是私有的，可以用新闻原图，`credits` 写摄影师和来源；这些图片只能放在私有数据目录里，**不能提交到任何公开仓库**。要公开分享的期刊只用自由授权的照片，同类示意照片在 `news.foot` 写明"示意"。选新闻时把"有没有好照片"当作筛选条件之一
- **照片裁切**：用 `photo_pos`（CSS background-position，如 `"center 30%"`）把人脸、动物的眼睛留在画面里，渲染后逐张检查

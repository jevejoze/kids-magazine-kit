# 讲读版（温暖好朋友有声陪伴）

讲读稿（narration 这一步）、语音（audio 这一步）、视频（video 这一步）共用。

每期除了图片和 PDF，再出一个 10–12 分钟的有声陪伴视频：本期全部页面图（按实际页数）当画面，音频不是照字读屏，而是**四位住在一起、性格各不相同的好朋友，拉着孩子一起翻杂志、边看边聊**。

好听的关键是**温暖、亲切、松弛、自然、有好奇心**：
- **去说教、去播报腔**：不要“老师提问、学生背书、旁白总结”的课堂味，也不要“欢迎收听、我们来看下一页、第一第二第三”的播音室或念 PPT 腔。
- **也去浮夸、去呛人**：不要“毒舌互怼”“把人怼得哑口无言”“公开处刑”“动不动赌吃电线”这种吵闹带刺的综艺腔。朋友之间的打趣是善意、轻快、让人会心一笑的。
- **闭眼也能听懂、听得进去**：每页抓一条主线讲透，有画面、有好奇、有呼吸感，孩子不看字、只用耳朵也能听得津津有味。

### 核心原则与红线

- **像真人聊天，不要播报腔和清单腔**：
  - 严禁“欢迎收听”“今天的主题是”“我们来看第一页”“看完了/讲完了/做完/弄懂了接下来看……”等机械报幕和收尾套话；
  - 也不要用“XX先放一放，我们来看……”这种变相套话硬凑转场；
  - 不要念“第一……第二……第三……”式的条目清单，把信息拆成伙伴之间你一言我一语的自然聊天。
- **转场轻巧自然，不硬掰**：
  - 上一页的话题如果能自然顺出联想，就用半句轻巧带过去；接不顺就直接把孩子带进下一页的画面里（如“哎，翻过来这张照片可真有意思！”），干脆利落；
  - 如果数据目录 `sfx/` 里有现成音效，可以适度点缀氛围（如开场铃、翻页、敲门），但**绝不依赖音效当拐杖**——没有配音效时，靠台词本身就能自然推进。
- **亲切留白，不用课堂指令**：
  - 不说“请先按暂停键思考一下”这类命令式口吻；像朋友聊天一样轻轻松松把问题抛给孩子（如“给你几秒钟想想，你觉得呢？”或团子狗小声琢磨“嗯……换作你，会怎么猜呀？”），留出 3–5 秒停顿（`pause: 3`–`5`），画面叠上温和的 `hold` 提示（如 `hold: "⏸ 猜猜看"`）。
- **英文融入自然，不搞跟读教学、不搞机械点名**：
  - 波波鼠随兴说一句贴合语境的英文短句，伙伴顺着聊天内容自然接住，顺口把核心英文词和意思融进回应里，让孩子在语境里听懂——绝不搞单词领读，也不要每条都套“外……外什么猫？→ wildcat，就是野猫的意思”这种复读机模板。
- **情绪跟着内容走**：
  - 温情思乡的故事就温柔细腻，奇趣冷知识就轻快好奇，探险悬念处才收紧节奏——不要强行把每一页都演成大呼小叫的闹剧或生死大片。

### 写法：`narration` 字段

讲读稿是 narration 这一步的 `issue/narration.json`，按页排列，`card` 对应 card-N.png，按本期实际渲染出来的页序编号——领任务单（`node scripts/pipeline.mjs ticket <issue> narration`）时，「本期骨架」一节已经按这一期实际出的栏目列好每页的卡号、句数上限和这个栏目自己的 `narrate.md` 写法，不用照哪个栏目固定排第几页去猜：

```json
{"narration": [
  {"card": 1, "thread": "半夜十二点多，太阳还挂在天上", "lines": [
    {"who": "dog", "lang": "zh", "text": "早呀小满！哈欠……快帮我看看，天怎么还没黑？", "emotion": "困倦", "sfx": "chime"},
    {"who": "owl", "lang": "zh", "text": "哈哈，这张照片可是在半夜十二点四十四分拍的。", "emotion": "开心"},
    {"who": "dog", "lang": "zh", "text": "半夜十二点多？太阳怎么还亮晶晶地挂在海面上呀！", "emotion": "惊讶"},
    {"who": "mouse", "lang": "en", "text": "Looks like the sun forgot its bedtime!"},
    {"who": "dog", "lang": "zh", "text": "它真忘了睡觉吗？给你几秒钟想想，会是为什么呀？", "emotion": "神秘", "pause": 5, "hold": "⏸ 猜猜看"}
  ]},
  {"card": 6, "thread": "鼹鼠第一次坐船，玩得舍不得上岸", "lines": [
    {"who": "narrator", "lang": "zh", "text": "小船轻轻晃着，鼹鼠把爪子伸进清凉的河水里，笑得合不拢嘴。", "emotion": "温柔"},
    {"who": "mouse", "lang": "en", "text": "Simply messing about in boats!", "rate": "slow"},
    {"who": "narrator", "lang": "zh", "text": "河鼠说，没有什么比在小船里瞎忙活更快乐的事啦。", "emotion": "开心"},
    {"who": "dog", "lang": "zh", "text": "听得我都想钻进小船里晒太阳啦——可前面那道急弯，他们过得去吗？", "emotion": "神秘", "pause": 3, "hold": "⏸ 猜一猜"}
  ]}
]}
```

- `who`：`narrator`（旁白）`dog` `mouse` `owl` `raccoon`
- `lang`：`zh` 或 `en`，决定用哪个声音
- `thread`（每页一个）：这一页的主线，≤ 30 字，只给写稿用，不念出来
- `emotion`：这句的语气，中文句必填，从这几个里选：`平静` `开心` `兴奋` `惊讶` `神秘` `紧张` `困倦` `得意` `委屈` `温柔`。语音合成支持情绪控制时照此念，不支持就忽略
- `sfx`：这句前面加的音效，仅从 `data/sfx/` 里确实存在的文件名选（如 `chime` 开场铃、`page` 翻页、`door` 开门、`drum` 悬念鼓点）；文件不存在时脚本会自动跳过，不要写依赖音效才听得懂的台词
- `pause`：这句念完后停几秒。**一般不写**，video 这一步按对话节奏自动定（同一角色接着说 0.22 秒、换人接话 0.32 秒、问句后 0.6 秒）；只在留给孩子想一想或故事悬念处写，每页最多一处 ≥ 3 秒。`repeat`：念几遍；`rate`：`slow` 表示放慢 20%
- `hold`：停顿期间画面上叠一行温和提示（如“⏸ 猜猜看”“🔍 找找线索”“💭 说说你的想法”）
- `pron`：这一句里多音字的读音，如 `{"在行": "zai4 hang2"}`（声调数字写在音节后，轻声写 5）。常用词已在 `scripts/polyphones.json` 里，只有词典没收、又容易读错的才写

### 怎么写

写稿顺序、错例和对例在 `pipeline/stages/narration.md`；每一页具体怎么讲，照任务单「本期骨架」里那个栏目自己的 `narrate.md`（也能在 `sections/<id>/narrate.md` 单独翻看）。写完跑 `node scripts/pipeline.mjs check <issue>` 改到没有 `[narration]` 报错：全期共用的规矩（旁白占比、语气起伏、数字读法、总长……）在这里统一查，这一页专属的规矩由那个栏目包自己的 `check.mjs` 查。最要紧的几条：

- **一页一条主线**：先写 `thread`，和主线无关的细节不讲；一页只讲一个数字，配一个孩子摸得着的比较，年份、日期不念
- **温暖聊天感，告别播报腔与呛人腔**：像朋友并肩翻杂志边看边聊；不写“看完了/讲完了”“XX先放一放”“第一第二第三”这类套话，也不写带刺挖苦或强行吵架
- **叙述归旁白，说话归角色**：角色不说自己的名字；旁白只交代画面、场景与动作，全期占 ≤ 40%（连载页除外），不做说教总结
- **每页至少一个自然的反应回合**：有人先猜一个好玩的答案、被照片吓一跳或提出直觉疑惑，另一位伙伴笑着接住、解开或打趣回去
- **用口语重新说，英文自然接住**：不照着页面念，同一件事只说一遍；波波鼠自然说英文短句，同伴顺着语境带出核心词和意思，绝不搞单词领读或复读机式点名
- **不念答案**：封面答案留给今日一问；谜题、真的假的的答案倒印在本页底部；信箱不公布上期答案
- 数字写成读法，每句 ≤ 30 字或 ≤ 12 个英文词，一个角色最多连说 3 句；全期 10–12 分钟，约 1800–2800 字
- 孩子的名字可以自然出现在问候和信箱里（如“早呀小满”），这属于数据目录里的内容

### 产出

讲读稿是流水线 narration 这一步，语音是 audio 这一步，视频是 video 这一步（`scripts/make_video.mjs` / `scripts/make_video.py`）。默认用 Azure 语音（`scripts/tts_azure.mjs`），也可按数据目录 `voices/` 配合 MiMo、ElevenLabs、VoiceStudio 合成，约定见 `pipeline/stages/audio.md`。

- 画面用本期全部的 card-N.png，按 `card` 顺序播放。脚本先把整期声音拼成一条音轨、记下每页的起点，画面按这些时间点一次编码，声音和画面不会错位
- 翻页：一页说完停 0.25 秒 → 0.6 秒淡入淡出 → 新页完全出现后再停 0.3 秒才开口；`sfx/page` 存在就在翻页时播放
- 每句会去掉合成语音首尾自带的静音，并统一音量，换声音时不会忽大忽小；`sfx/bgm` 存在就以很低的音量循环垫在底下
- `pause` `repeat` `rate` `hold` `sfx` 都要体现出来；`hold` 的提示在停顿期间显示在画面上
- 成品放在 `issue/final/`；生成不了声音时，把讲读稿整理成一份“家长讲读稿”，让家长照着念
- 每个角色用哪个声音写在数据目录 `voices/` 里；音效放在 `data/sfx/`

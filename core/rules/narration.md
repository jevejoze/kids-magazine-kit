# 讲读版（有声视频）

讲读稿（第 50 步）、语音（第 60 步）、视频（第 70 步）共用。

每期除了图片和 PDF，再出一个 10–12 分钟的讲读视频：本期全部页面图（平时 8 张，周一、周五 9 张）当画面，编辑部像一档儿童电台节目那样**把这一期讲给孩子听**。好听的关键是**紧凑**和**像真的在聊天**：每页抓一条主线讲透，角色之间你一句我一句地接话，只在真要孩子动脑的地方停下来。孩子不看字、只听也能听懂、听得进去。

### 写法：`narration` 字段

讲读稿是第 50 步的 `issue/50-narration.json`，按页排列，`card` 对应 card-N.png，按渲染出来的顺序编号（平时 1 = 封面，2 今日一问，3 小剧场，4 挑战，5 环球小报，6 真的假的，7 经典连载，8 信箱；周一在今日一问后面多一张怪物档案，往后顺延；周五在经典连载后面多一张周末思辨，信箱顺延）：

```json
{"narration": [
  {"card": 1, "thread": "半夜的太阳还挂在天上", "lines": [
    {"who": "narrator", "lang": "zh", "text": "叮咚！小满早上好，《小满早知道》开播啦！", "emotion": "开心", "sfx": "chime"},
    {"who": "dog", "lang": "zh", "text": "咦？这张照片……真是半夜拍的？太阳怎么还挂在天上！", "emotion": "惊讶"},
    {"who": "narrator", "lang": "zh", "text": "你选哪个？先按暂停，想一想再继续。", "emotion": "温柔", "pause": 5, "hold": "⏸ 先暂停猜一猜"}
  ]},
  {"card": 6, "thread": "鼹鼠第一次坐船", "lines": [
    {"who": "mouse", "lang": "en", "text": "Simply messing about in boats!", "rate": "slow"},
    {"who": "narrator", "lang": "zh", "text": "你猜，鼹鼠掉进河里以后会怎样？", "emotion": "神秘", "pause": 3, "hold": "⏸ 猜一猜"}
  ]}
]}
```

- `who`：`narrator`（旁白）`dog` `mouse` `owl` `raccoon`
- `lang`：`zh` 或 `en`，决定用哪个声音
- `thread`（每页一个）：这一页的主线，≤ 30 字，只给写稿用，不念出来
- `emotion`：这句的语气，中文句必填，从这几个里选：`平静` `开心` `兴奋` `惊讶` `神秘` `紧张` `困倦` `得意` `委屈` `温柔`。语音合成支持情绪控制时照此念，不支持就忽略
- `sfx`：这句前面加的音效，从 `data/sfx/` 里有的文件名选（如 `chime` 开场铃、`page` 翻页、`slurp` 吸溜声、`door` 开门、`ding` 答对、`drum` 揭晓）；文件不存在就跳过
- `pause`：这句念完后停几秒。**一般不写**，第 70 步按对话节奏自动定（同一角色接着说 0.2 秒、换人接话 0.3 秒、问句后 0.6 秒）；只在要孩子思考或跟读的地方写，每页最多一处 ≥ 3 秒。`repeat`：念几遍；`rate`：`slow` 表示放慢 20%
- `hold`：停顿期间画面上叠一行提示（如"⏸ 先暂停猜一猜""🗣 跟着读""🔍 回头找线索"）
- `pron`：这一句里多音字的读音，如 `{"在行": "zai4 hang2"}`（声调数字写在音节后，轻声写 5）。常用词已在 `scripts/polyphones.json` 里，只有词典没收、又容易读错的才写

### 声音（每个角色固定一种，让孩子一听就知道是谁）

| 角色 | 中文 | 英文 |
|---|---|---|
| 旁白 | 温暖、像讲睡前故事的女声 | 英式英语 |
| 团子狗 | 童声，憨憨的、慢一点，爱打哈欠 | — |
| 波波鼠 | 有点蹩脚的中文 | 英式英语小女孩，语速自然 |
| 咕咕博士 | 沉稳的男声，讲到关键处放慢 | 英式英语 |
| 捣蛋浣熊 | 调皮、语气夸张，爱"哼" | 英式英语 |

选定的声音记在数据目录的 `profile.md`，之后每期沿用，不随意更换。

### 怎么写

每页怎么讲、写稿顺序、错例和对例全在 `pipeline/stages/50-narration.md`，写稿照它走，写完跑 `node scripts/pipeline.mjs check <issue>` 改到没有 `[50]` 报错。最要紧的几条：

- **一页一条主线**：先写 `thread`，和主线无关的细节不讲；一页只讲一个数字，配一个孩子摸得着的比较，年份、日期不念
- **只听也跟得上**：每句提到的人和东西前面都交代过；`50-narration.md` 的例句只示范结构，用本期内容重新造句
- **叙述归旁白，说话归角色**：角色不说自己的名字；旁白只开场、串词、交代场景，全期占 ≤ 40%（连载页除外）
- **每页至少一个反应回合**：团子狗猜错、误会或吓一跳，懂的角色接住；知识由咕咕博士说，团子狗负责惊讶和追问
- **用口语重新说**：不照着页面念，同一件事只说一遍；英文由波波鼠说成一句 3–8 个词的短句，团子狗接不住，有人翻译
- **不念答案**：封面答案留给今日一问；谜题、真的假的答案倒印在本页底部；信箱不公布上期答案
- 数字写成读法，每句 ≤ 30 字或 ≤ 12 个英文词，一个角色最多连说 3 句；全期 10–12 分钟，约 1800–2800 字
- 孩子的名字可以出现在问候和信里（如"小满早上好"），这属于数据目录里的内容

### 产出

讲读稿是流水线第 50 步，语音是第 60 步，视频是第 70 步（`scripts/make_video.py`）。默认用 Azure 语音（`scripts/tts_azure.mjs`）：免费档每月 50 万计费字符（汉字算 2 个），一期约 0.9 万（含多音字注音），够出 55 期左右；脚本会跳过已经合成过的句子，并报告用了多少字符。也可以换别的语音服务，只要按 `pipeline/stages/60-audio.md` 的约定放好音频。

- 画面用本期全部的 card-N.png，按 `card` 顺序播放。脚本先把整期声音拼成一条音轨、记下每页的起点，画面按这些时间点一次编码，所以声音和画面不会错位
- 翻页：一页说完停 0.25 秒 → 0.6 秒淡入淡出 → 新页完全出现后再停 0.3 秒才开口；`sfx/page` 存在就在翻页时播放
- 每句会去掉合成语音首尾自带的静音，并统一音量，换声音时不会忽大忽小；`sfx/bgm` 存在就以很低的音量循环垫在底下
- `pause` `repeat` `rate` `hold` `sfx` 都要体现出来；`hold` 的提示在停顿期间显示在画面上
- 成品放在 `issue/70-final/`；生成不了声音时，把讲读稿整理成一份"家长讲读稿"，让家长照着念
- 每个角色用哪个 Azure 声音写在 `data/voices/azure.json`（没写的用脚本里的默认声音），`--audition` 可以先合成一句试听；音效放在 `data/sfx/`

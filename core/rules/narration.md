# 讲读版（广播剧电影感音频底座）

讲读稿（narration 这一步）、语音（audio 这一步）、视频（video 这一步）共用。

每期除了图片和 PDF，再出一个 10–12 分钟的声音短剧（有声视频）：本期全部页面图（平时 8 张，周一、周五 9 张）当画面，**但音频绝不是读屏辅助，而是一部 10 分钟的声音短剧**。
彻底废除“老师提问、学生犯蠢、旁白做总结”的传统教学关系，改造成一群挤在阁楼里的搞笑死党；音频讲读版不再是读屏辅助，而是一部10分钟的声音短剧。好听的关键是**电影感、紧凑、死党张力与真实生活感**：每页抓一条主线讲透，死党之间你来我往、抢话吐槽、常识拆台，只在戏剧悬念处留白。孩子不看字、只听也能听懂、听得入迷。

### 核心底座原则与红线禁令

- **严禁出现所有播报腔和教学转场套话**：严禁“我们来看第一页”、“说到这个，波波鼠开门了”、“你觉得是为什么呢，先按暂停”、“看完了/讲完了/做完/弄懂了接下来看……”等任何播报腔、报幕腔、教学转场、说教套话。
- **转场全部用环境音效推进与角色争执引出**：转场绝不靠旁白报幕或生硬串词，全部用**环境音效**（如机械火花 `spark`、敲门 `knock`、嚼坚果 `crunch`、打翻工具箱、吸溜奶茶、纸箱吱呀等）推进，配合死党争执、抢夺道具、打赌或现场小意外自然引出下一页。
- **节奏留白取代指令式暂停**：彻底废除“你觉得是为什么呢，先按暂停”、“先暂停想一想再继续”等教师指令腔。留出 4–5 秒情绪真空（`pause: 4` 或 `pause: 5`），配合戏剧音效与角色小声嘀咕打赌（如“我赌五颗黑糖珍珠，他绝对猜不对！”、“这家伙要是能蒙对，我把这根电线嚼了！”），画面叠加轻巧的 `hold` 提示（如 `hold: "⏸ 思考时间"`），自然引发听众思考。

### 写法：`narration` 字段

讲读稿是 narration 这一步的 `issue/narration.json`，按页排列，`card` 对应 card-N.png，按本期实际渲染出来的页序编号——领任务单（`node scripts/pipeline.mjs ticket <issue> narration`）时，「本期骨架」一节已经按这一期实际出的栏目列好每页的卡号、句数上限和这个栏目自己的 `narrate.md` 写法，不用照哪个栏目固定排第几页去猜：

```json
{"narration": [
  {"card": 1, "thread": "半夜的太阳，阁楼装置短路了", "lines": [
    {"who": "raccoon", "lang": "zh", "text": "看好了！我的'极昼探测仪'绝对不会出错！", "emotion": "得意", "sfx": "spark"},
    {"who": "dog", "lang": "zh", "text": "可你把博士的闹钟烤焦了……而且，大半夜哪来的太阳？", "emotion": "困倦", "sfx": "crunch"},
    {"who": "owl", "lang": "zh", "text": "严谨地说，根据地轴倾角与极圈光照模型——等等，我的眼镜呢！", "emotion": "兴奋"},
    {"who": "raccoon", "lang": "zh", "text": "我赌五颗黑糖珍珠，他绝对猜不对！", "emotion": "得意", "pause": 5, "hold": "⏸ 思考时间"}
  ]},
  {"card": 6, "thread": "鼹鼠第一次坐船翻车", "lines": [
    {"who": "mouse", "lang": "en", "text": "No way! Simply messing about in boats!", "rate": "slow"},
    {"who": "dog", "lang": "zh", "text": "船都翻扣在泥里了，它怎么还笑得出来？", "emotion": "惊讶", "sfx": "splash"},
    {"who": "raccoon", "lang": "zh", "text": "要换成我的涡轮喷射器，我敢打赌它能直接飞上天！", "emotion": "得意", "pause": 4, "hold": "⏸ 猜一猜"}
  ]}
]}
```

- `who`：`narrator`（旁白）`dog` `mouse` `owl` `raccoon`
- `lang`：`zh` 或 `en`，决定用哪个声音
- `thread`（每页一个）：这一页的主线，≤ 30 字，只给写稿用，不念出来
- `emotion`：这句的语气，中文句必填，从这几个里选：`平静` `开心` `兴奋` `惊讶` `神秘` `紧张` `困倦` `得意` `委屈` `温柔`。语音合成支持情绪控制时照此念，不支持就忽略
- `sfx`：这句前面加的音效，从 `data/sfx/` 里有的文件名选（如 `spark` 火花、`chime` 开场铃、`page` 翻页、`slurp` 吸溜声、`door` 开门、`ding` 答对、`drum` 揭晓）；文件不存在就跳过
- `pause`：这句念完后停几秒。**一般不写**，video 这一步按对话节奏自动定（同一角色接着说 0.2 秒、换人接话 0.3 秒、问句后 0.6 秒）；只在要孩子思考或戏剧悬念处写，每页最多一处 ≥ 3 秒。`repeat`：念几遍；`rate`：`slow` 表示放慢 20%
- `hold`：停顿期间画面上叠一行提示（如"⏸ 思考时间""🗣 跟着读""🔍 回头找线索"）
- `pron`：这一句里多音字的读音，如 `{"在行": "zai4 hang2"}`（声调数字写在音节后，轻声写 5）。常用词已在 `scripts/polyphones.json` 里，只有词典没收、又容易读错的才写

### 怎么写

写稿顺序、错例和对例在 `pipeline/stages/narration.md`；每一页具体怎么讲，照任务单「本期骨架」里那个栏目自己的 `narrate.md`（也能在 `sections/<id>/narrate.md` 单独翻看）。写完跑 `node scripts/pipeline.mjs check <issue>` 改到没有 `[narration]` 报错：全期共用的规矩（旁白占比、语气起伏、数字读法、总长……）在这里统一查，这一页专属的规矩（如挑战不说答案在哪公布、环球小报三条都讲到）由那个栏目包自己的 `check.mjs` 查。最要紧的几条：

- **一页一条主线**：先写 `thread`，和主线无关的细节不讲；一页只讲一个数字，配一个孩子摸得着的比较，年份、日期不念
- **严禁播报腔和教学转场套话**：严禁“我们来看第一页”、“说到这个，波波鼠开门了”、“你觉得是为什么呢，先按暂停”、“看完了/讲完了”等套话
- **转场全部用环境音效推进与角色争执引出**：以机械火花、敲门、嚼坚果等推进，由死党争执打赌自然引出下一页
- **节奏留白取代指令式暂停**：留出 4–5 秒情绪真空，配合戏剧音效与角色小声嘀咕打赌（“我赌五颗黑糖珍珠，他绝对猜不对！”），自然引发听众思考
- **叙述归旁白，说话归角色**：角色不说自己的名字；旁白只交代开场、环境与动作细节，全期占 ≤ 40%（连载页除外），严禁总结说教
- **每页至少一个死党反应回合**：团子狗常识拆台、博士理论狂飙被打断、浣熊短路嘴硬打赌，角色之间自然接话碰撞
- **用口语重新说，英文不搞跟读教学**：不照着页面念，同一件事只说一遍；英文由波波鼠自然流露或带出核心生词，绝不搞跟读教学
- **不念答案**：封面答案留给今日一问；谜题、真的假的答案倒印在本页底部；信箱不公布上期答案
- 数字写成读法，每句 ≤ 30 字或 ≤ 12 个英文词，一个角色最多连说 3 句；全期 10–12 分钟，约 1800–2800 字
- 孩子的名字可以出现在问候和信里（如"小满早上好"），这属于数据目录里的内容

### 产出

讲读稿是流水线narration 这一步，语音是audio 这一步，视频是video 这一步（`scripts/make_video.py`）。默认用 Azure 语音（`scripts/tts_azure.mjs`）：免费档每月 50 万计费字符（汉字算 2 个），一期约 0.9 万（含多音字注音），够出 55 期左右；脚本会跳过已经合成过的句子，并报告用了多少字符。也可以换别的语音服务，只要按 `pipeline/stages/audio.md` 的约定放好音频。

- 画面用本期全部的 card-N.png，按 `card` 顺序播放。脚本先把整期声音拼成一条音轨、记下每页的起点，画面按这些时间点一次编码，所以声音和画面不会错位
- 翻页：一页说完停 0.25 秒 → 0.6 秒淡入淡出 → 新页完全出现后再停 0.3 秒才开口；`sfx/page` 存在就在翻页时播放
- 每句会去掉合成语音首尾自带的静音，并统一音量，换声音时不会忽大忽小；`sfx/bgm` 存在就以很低的音量循环垫在底下
- `pause` `repeat` `rate` `hold` `sfx` 都要体现出来；`hold` 的提示在停顿期间显示在画面上
- 成品放在 `issue/final/`；生成不了声音时，把讲读稿整理成一份"家长讲读稿"，让家长照着念
- 每个角色用哪个 Azure 声音写在 `data/voices/azure.json`（没写的用脚本里的默认声音），`--audition` 可以先合成一句试听；音效放在 `data/sfx/`

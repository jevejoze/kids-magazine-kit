# 14 谜题

**目标**：一道四五年级奥数入门难度的题，和本期主题挂钩，唯一解。

**读**：`issue/00-brief.json`

**写**：`issue/14-puzzle.json`

```json
{
  "_meta": {"stage": "14-puzzle", "by": "", "at": ""},
  "title": "🐝 谜题：一圈又一圈的蜂巢",
  "body": "题干，用 <br> 换行，小问用 ①②③",
  "slots": ["① ___ 个", "② ___ 个", "③ ___ 圈"],
  "answer": "① 18 个；② 37 个；③ 5 圈",
  "solution": "完整推导过程，并说明为什么答案唯一"
}
```

**规则**
- 题型：4 个以上对象、3–4 条线索的逻辑排序；或需要两步以上推理的数学题
- 题干 ≤ 120 字；`slots` 是留给孩子填答案的格子，2–4 个
- 难度：孩子要停下来想一想才能做出来；宁可偏难，题干里给一点提示托底

**自检**：按 `solution` 自己从头做一遍；逻辑题把所有排列试一遍，确认只有一个满足全部条件

# 14 谜题

**目标**：挑战页的全部内容：捣蛋浣熊一句挑衅 + 一道四五年级奥数入门难度的题，和本期主题挂钩，唯一解。面向平板阅读，情境、条件和提问分开排版，不留手账、草稿和手写答案格。答案在本页底部倒印，不在下一期公布。

**读**：`issue/00-brief.json`

**写**：`issue/14-puzzle.json`

```json
{
  "_meta": {"stage": "14-puzzle", "by": "", "at": ""},
  "taunt_zh": "哼，数格子？我数得比蜜蜂还快！",
  "taunt_en": "Can you count faster than a bee?",
  "prop": "magnifier",
  "title": "🐝 谜题：一圈又一圈的蜂巢",
  "body": "简短说明题目情境、对象和规则。",
  "clues": ["条件一，每项只写一个条件，不手写编号。", "条件二，明确先后、数量或相邻关系。", "条件三，排除容易误解的说法。"],
  "question": "明确问孩子要得出什么结果，以及按什么顺序回答。",
  "answer": "① 18 个；② 37 个；③ 5 圈",
  "solution": "完整推导过程，并说明为什么答案唯一"
}
```

**规则**
- `taunt_zh` ≤ 20 字，嘴硬、挑衅、和题目有关；`taunt_en` 是一句简单的英文版（≤ 10 个词）；`prop` 是浣熊的道具（见 SKILL.md 角色写法，可空）
- 周六、周日也照常出谜题
- 题型：4 个以上对象、3–4 条线索的逻辑排序；或需要两步以上推理的数学题
- `body` ≤ 120 字，只交代情境；`clues` 每条一个条件，模板自动编号；`question` 单独提出问题，明确队首/队尾、单位或回答顺序。情境、条件和问题合计 ≤ 240 字。新稿不写 `slots`。
- `answer` 是简短明确的最终答案，必须非空；`solution` 保留完整推导供审核，不全部塞进页底。英文三关启用时，其答案也在本页倒印。
- 旧稿只有 `body` 仍能渲染，但新稿必须按上述字段拆分。
- 难度：孩子要停下来想一想才能做出来；宁可偏难，题干里给一点提示托底

**自检**：按 `solution` 自己从头做一遍；逻辑题把所有排列试一遍，确认只有一个满足全部条件

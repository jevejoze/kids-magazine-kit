# 16 信箱

**目标**：杂志的最后一页，用来收孩子的反馈。页面上固定有 5 个问题，由模板生成：👍 最喜欢哪一页、👎 哪一页不太喜欢、今天难不难、💡 今天想到了什么有趣的问题、👀 今天看到了什么有意思的事。这一步只写页面上方的几句话。

**读**：`issue/00-brief.json`（`last_answers`、`last_feedback`、`send_note`）、`data/letters.md`、周六读上一期的 `issue/08-think.json`

**写**：`issue/16-mailbox.json`

```json
{
  "_meta": {"stage": "16-mailbox", "by": "", "at": ""},
  "hello": "小满早上好！你问为什么没有木乃伊猫——其实有，而且很多！",
  "answers": "封面：地球是斜着转的；谜题：① 18 个 ② 37 个 ③ 5 圈",
  "ask_zh": "如果你是蜜蜂，会把家盖成什么形状？",
  "send_note": "说给妈妈听"
}
```

**规则**
- `hello` ≤ 60 字：一句问候。收到了上期打卡，就接住她的一句话（原话、她想到的问题或她看到的事），没收到就由一个角色说一句和本期主题有关的小事
- `answers` ≤ 100 字，一行公布上期封面和谜题的答案，和 `last_answers` 一致；没有上期就不写
- `ask_zh`（可选）≤ 30 字，一个和本期内容有关、要说理由的问题
- 周六：接住周五的周末思辨，`hello` 或 `ask_zh` 问一句聊得怎么样（如"昨天的话题，家里谁说服了谁？"）；周五的信箱不重复思辨话题
- 不写长信，不放集章、奖励；连载的"猜一猜"留给下一回连载自己回应
- 不编造孩子说过的话

**自检**：字数；公布的答案和 `last_answers` 一致；`hello` 里引用的话在 `letters.md` 或 `feedback.jsonl` 里找得到

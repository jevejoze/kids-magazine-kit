# 50 讲读稿

**目标**：把这一期写成一档 10–12 分钟的**温暖好朋友有声陪伴节目**。听起来就像四位性格可爱的好朋友，拉着孩子一起翻开这期杂志、边看边聊——亲切、松弛、好奇、好玩，孩子只用耳朵也能听得懂、听得进去。

**读**：`issue/issue.json`、`issue/review.md`（确认已通过）、`issue/cover.json`（照片的来历）、`issue/comic.json` 的 `sources`、`issue/story.json`（本期有才读）、`issue/news.json`（`talk`、`photo_shows`）、`issue/serial.json`、`data/serial-bible.md`（或 `data/state/serial-book/config.md`）、`data/profile.md`（称呼、选定的声音）、`core/rules/narration.md`

**写**：`issue/narration.json`

```json
{"_meta": {"stage": "narration", "by": "", "at": "", "content_hash": "<当前内容指纹>", "ticket": "<任务单指纹>"},
 "narration": [{"card": 1, "thread": "半夜十二点的太阳，团子困得要命", "lines": [
   {"who": "dog", "lang": "zh", "text": "早呀小满！哈欠……快帮我看看，天怎么还没黑呀？", "emotion": "困倦", "sfx": "chime"}
 ]}]}
```

写稿前运行 `node scripts/pipeline.mjs fingerprint <issue>`，把指纹放进 `_meta.content_hash`；再领任务单 `node scripts/pipeline.mjs ticket <issue> narration`，单上的指纹放进 `_meta.ticket`。必须先确认审稿通过且指纹有效；内容变化后重写对应台词并更新指纹，不能直接给旧稿换指纹。

`card` 按本期实际出的栏目编号，不固定哪个栏目排第几页：领任务单时「本期骨架」一节已经按这期实际页序（包括海报版多页新闻）列好每页的卡号、句数上限和那个栏目自己的 `narrate.md`，照着写就行。

每句的字段：`who` `lang` `text` `emotion`（中文句必填）`sfx` `pause` `repeat` `rate` `hold` `pron`，取值见 `core/rules/narration.md`。每页另写一个 `thread`：这一页要让孩子记住的那一件事，≤ 30 字，只给写稿用，不念出来。

## 写稿顺序（每页都照这五步走）

1. **定主线**：先写 `thread`。一页只讲透这一件事，页面上和主线无关的细节（星级、年份、日期、第二个数字）一律不讲。经典单页环球小报的 `thread` 要把几条新闻都点到；海报分页版每张卡写本条新闻的主线。
2. **定基调与角色**：先感受这一页的情绪（好奇？好笑？惊叹？温柔？紧张？），再按角色性格分工（对齐 `cast/default.json`）：
   - **团子狗**：憨厚嘴馋、好奇心旺、慢半拍；爱先凭直觉猜一个好玩或歪掉的答案，再用接地气的日常小问题替孩子追问；不用“等等”当口头禅（换用“咦？”“慢着！”“不对呀！”），完全不懂英文，不替别人翻译英文单词
   - **咕咕博士**：沉稳温和、博学又带点小迷糊；聊到好玩机制眼睛发亮，善用生活实物打比方，解释英文时不端着架子；讲动手实验时不提前说破结果
   - **捣蛋浣熊**：鬼点子多、爱动手做小发明、嘴硬心软；喜欢出小谜题或轻松打个小赌，被看穿会不好意思地挠头干咳，打趣都是善意的
   - **波波鼠**：从伦敦来的机灵小伙伴，语速轻快；自然穿插地道英文短句或感叹，绝不端着领读单词，偶尔带着笑意轻轻打趣大家
   - **旁白**：温暖、像陪孩子翻书聊天的亲切声音；交代画面、场景、动作与轻巧转场，绝不做总结说教
3. **写骨架**：先用一行一句列出这一页的“谁 → 做什么”，再填台词。每页至少有一个**自然的反应回合**——有人先猜歪、被画面惊到、或者冒出直觉疑惑，另一个伙伴笑着接住、解开或打趣回去。
4. **写口语台词**：叙述归旁白，说话归角色；用朋友聊天的口语把页面内容重新讲活，**不照着页面念，不念“第一、第二、第三”清单，不用“XX先放一放”凑转场**。
5. **读出声听一遍、跑检查**：假装闭着眼睛听整期音频——每句提到的东西前面都交代过吗？相邻两句接得顺吗？有没有连续两页用了同样开头？有没有哪句听起来像老师讲课，或者像在吵架挖苦？删掉重复、客套、生硬的句子；最后跑 `node scripts/pipeline.mjs check <issue>`，改到没有 `[narration]` 报错。

## 硬规矩（脚本会查）

全期共用的规矩在 `pipeline-lib.mjs` 统一查；第 7、11、12、13、16、17 条由对应栏目包的 `check.mjs`（`checkNarration`）查，写法按下表：

| # | 规矩 | 查法 |
|---|---|---|
| 1 | 角色不说自己的名字，不用第三人称讲自己的动作 | 角色台词里出现自己的名字就报错（“我是团子狗”除外） |
| 2 | 旁白只负责交代画面、场景、动作与轻巧转场 | 除连载页外，旁白占全期句数 ≤ 40%，单页 ≤ 60% |
| 3 | 语气要有起伏 | 中文句都写 `emotion`（仅限 10 个规定词）；全期“平静” ≤ 40% |
| 4 | 不照着页面念 | 今日一问、怪物档案、小剧场、环球小报、连载、周末思辨：和页面叙述文字连续 10 个字相同的句子，每页最多 2 句或全页的四分之一。角色对白、要孩子回答的问题不算 |
| 5 | 同一件事只说一遍 | 同一页里两句有连续 8 个字相同就报错 |
| 6 | 转场自然、不套收尾套话 | “看完了 / 讲完了 / 做完 / 弄懂了”这类收尾式串词全期最多 2 处（尽量 0 处，也别用“XX先放一放”） |
| 7 | 不说答案在哪一期公布 | 挑战页、真的假的都不说“答案明天见 / 信箱里见”（答案倒印在本页底部）；信箱不公布上期答案 |
| 8 | 一页一个数字 | 带单位的数字（三十五克、四十六厘米、一百小时）每页最多 1 个，环球小报每条新闻 1 个、整页最多 3 个；同一个数字说两遍只算一个。小剧场、挑战、连载不查 |
| 9 | 不念年份和日期 | “二零零九年”“十月十九日”这类一律删；要说时间就说“十几年前”“上个星期” |
| 10 | 不照抄本文件的例句 | 和下面「写法：错的和对的」里的句子连续 8 个字相同就报错。例句只示范句子怎么搭，话题故意和任何一期都无关 |
| 11 | 环球小报每条都讲到 | 本页新闻的关键词 `word.en` 都要在波波鼠的英文短句里出现（≥ 3 个词） |
| 12 | 今日一问以“你也可以试试”收尾 | 说了“试试”之后最多再有一句 |
| 13 | 信箱说给对的人、不念旧问卷 | “说给 / 发给 / 告诉某某”要和 `send_note` 里的人一致；不念“最喜欢哪页/今天难不难”等机械问卷；明天的预告不重复小剧场的 `tbc` |
| 14 | 英文在聊天里自然接住 | 今日一问、怪物档案、环球小报：波波鼠的每句英文后 3 句内，要有别的角色在中文句里自然带上其中一个核心英文词并融进意思里（不要机械复读“外什么猫→就是野猫的意思”） |
| 15 | 先交代再提起 | 角色的问句和同页后面旁白的交代有连续 4 个字相同就报错：旁白的交代挪到问句前面 |
| 16 | 连载吐槽由认领的成员自己说 | 连载页（`kind: "book"`）要有 `crew.who` 那个角色的台词；旁白只用一句引出，不替他念（全篇单旁白模式除外） |
| 17 | 信箱不出猜谜 | 信箱页不说“你猜” |

另外还查：每页 `thread`、句数上限、每句 ≤ 30 字或 ≤ 12 个英文词、同一角色最多连说 3 句（连载页由旁白一人念时除外）、每页 ≥ 3 秒的停顿最多一处、中文里不写阿拉伯数字或 `%`、不出现“思维本领/今天练”等说教词、总字数（建议 1800–2800 字）。

## 写法：错的和对的

下面的例子只示范**自然聊天的搭法**。话题（章鱼、蜂鸟、火山、企鹅……）故意选得和任何一期都无关；写稿时照这个感觉，用这一期自己的内容重新造句，例句里的词句一句都不要搬。

**① 叙述和对白分开**
- ❌ `mouse`：波波鼠把信封倒过来，抖出一片羽毛！
- ✅ `narrator`：波波鼠把信封倒过来抖了抖。 → `mouse`：Look! 一片羽毛！

**② 用自然的猜测和幽默打趣，代替老师问答或刻薄互怼**
- ❌ `dog`：企鹅的脚为啥不冻僵？ → `owl`：脚上的血管会互相取暖。（干巴巴像背答案）
- ❌ `raccoon`：笨蛋！我赌五颗珍珠你肯定猜不出来！（太呛人、不友好）
- ✅ `dog`：我知道！企鹅偷偷穿了袜子！ → `owl`：哈，哪来的袜子。它脚上的血管会互相取暖。

**③ 知识由懂的人生动讲，团子狗负责好奇和共鸣**
- ❌ `dog`：哈哈，蜂鸟的心一分钟跳一千多下呢！
- ✅ `owl`：蜂鸟的心，一分钟跳一千多下。 → `dog`：一千多下？那得多累啊！ → `narrator`：你的心一分钟才跳八十来下。

**④ 数字少而落地**：一页只讲一个数字，紧跟一个孩子摸得着的比较（几大勺、几辆公交车、开车多久、自己的心跳）。年份、日期、第二个尺寸都删掉。

**⑤ 英文自然接在聊天里，不做复读机式点名**
波波鼠说一句 3–8 个词的自然短句 → 同伴顺着语境接话，把核心英文词自然融进中文回应里（让孩子一听就懂，不硬拗、不重复套路）：
- ❌ `mouse`：Volcano, a fire mountain! → `dog`：记住了，火山！（团子狗不能自己翻译，也缺原词）
- ❌ `mouse`：The volcano is waking up! → `dog`：喔……喔什么诺？ → `owl`：volcano，就是火山的意思。（偶尔一次还行，每条都套“X……X什么Y→就是XX的意思”非常生硬）
- ✅ `mouse`：The volcano is waking up! → `owl`：哇，volcano 火山真的要醒啦，快看那股白烟！
- ✅ `mouse`：The volcano is waking up! → `dog`：咦，波波刚才说谁醒啦？ → `owl`：她说 volcano，就是这座火山要醒啦。
团子狗不懂英文，只负责好奇发问或偶尔念歪逗乐；带出英文原词和中文意思由咕咕博士（或旁白）顺嘴自然接住。

**⑥ 拆掉“第一、第二、第三”的清单腔**
- ❌ `owl`：第一，这是老话传开的。第二，果蝠眼睛很大。第三，百科说视力很好。
- ✅ `owl`：先查查这话打哪儿来的，原来只是句老话。 → `dog`：老话也会说错呀？ → `owl`：你看果蝠长着圆溜溜的大眼睛，天黑照样找果子吃呢。

**⑦ 只有一个声音念时，先点出是谁在说**（`serial-bible.md` 规定连载全部由旁白念时）
- ❌ `narrator`：今晚谁也别想睡觉！
- ✅ `narrator`：老船长一拍桌子，瞪着眼睛说：今晚谁也别想睡觉！

**⑧ 转场轻巧顺势，禁止“看完了”也禁止“XX先放一放”**
- ❌ 新闻看完了，我们来看看下一页。
- ❌ 刚才的故事先放一放，手机上又刷到一条新视频。
- ✅ 刚才那只会开门的章鱼——网上居然有人说它还会偷看电视呢！
- ✅ （如果两页话题不沾边，直接入画就好，绝不硬扯）哎，翻过来这张照片里，怎么有只小鸟在敲玻璃门呀？

**⑨ 只听也跟得上：先交代，再提起**
- ❌ `dog`：会不会是那把钥匙开的？（前面没人说过有钥匙）
- ✅ `narrator`：团子狗从口袋里掏出一把小钥匙。 → `dog`：会不会是这把开的？

**⑩ 每句接住上一句，说人话、有呼吸感**
后一句要回应、追问、解释或顺着前一句往前走，别把两句互不沾边的事实硬拼在一起：
- ❌ `narrator`：这张照片是几年前在海边拍的。 → `owl`：这座山底下全是滚烫的岩浆！
- ✅ `dog`：咦，山顶上怎么白白的？ → `owl`：那是雪。这座山其实是一座火山。 → `dog`：火山不是烫得冒火吗？雪怎么不化？

## 每页怎么讲（与各栏目 `narrate.md` 对齐）

领任务单时「本期骨架」已经附上了本期实际出刊栏目的 `narrate.md`，写稿时以任务单骨架为准；下表是全栏总览：

| 页 | 主持 | 温暖聊天骨架 |
|---|---|---|
| 封面（≤ 12 句）| 封面成员 + 旁白 | 温暖自然地跟孩子打个招呼（叫孩子名字，不做“欢迎收听/今天是XX日”播报腔）→ 封面上的 1–2 位伙伴顺着照片里最让人惊奇的细节聊起来 → 两三句层层递进走到主问题 → 团子狗抛出主问题，亲切留 5 秒给孩子猜。不说答案 |
| 今日一问（≤ 26 句）| 咕咕博士 + 团子狗 + 波波鼠 | 团子狗先凭直觉猜个好玩的错答案 → 咕咕博士笑着接住，用一个生活里的贴切比喻讲清机制 → 团子狗至少插嘴两次，顺着追问往下走一层 → 一个记得住的数字配生活比较 → 波波鼠一句自然英文总结，同伴顺嘴带词接住 → 以温和的“你也可以试试……”收尾（后面最多再有一句） |
| 怪物档案（周一，≤ 14 句）| 咕咕博士 + 团子狗 + 波波鼠 | 咕咕博士用带点神秘感的口吻聊古人画里的海怪 → 团子狗吓一跳或半信半疑 → 科学家查到的一条关键证据 → 揭晓真实原型，比比右边照片和传说差在哪 → 波波鼠用短句念英文名，同伴自然接住。星级、编号不念 |
| 小剧场（≤ 30 句）| 旁白 + 四位成员 | 像轻松好听的探案广播剧：先交代画面动作再开口，角色各抒己见、有来有往；关键线索处给足声音细节或短暂停顿；紧张处放慢 → 旁白念侦探笔记（照 `story.json` 的 `clue`），停 3–5 秒 → 结尾留温和悬念 |
| 挑战（≤ 12 句）| 捣蛋浣熊 + 旁白 + 团子狗 | 浣熊笑嘻嘻地出题邀战 → 浣熊和旁白把情境和线索说清楚（或引导孩子看图比划）→ 团子狗兴冲冲乱猜一个，被浣熊笑眯眯拦回来 → 给一句贴心思路小提示 + 停 3–5 秒 → 提醒想好后把平板倒过来看本页底部答案 |
| 环球小报（≤ 24 句，海报版每张卡 6–10 句）| 波波鼠 + 咕咕博士 + 团子狗 + 旁白 | 每条先带孩子“看见”照片里的奇趣画面（`photo_shows`）→ 用 `talk` 聊故事背景、配一个摸得着的尺度类比、自然连到孩子生活里 → 波波鼠用一句自然英文短句带出 `word.en`，伙伴顺着情绪和意思接住并带出原词 → 经典版最后念 `ask_zh` 停 3 秒（海报版页面无尾题则自然收尾） |
| 真的假的（≤ 12 句）| 旁白 + 团子狗 + 咕咕博士（可选浣熊）| 旁白用平时刷手机/听人聊天的自然口吻念出说法 → 团子狗的快脑袋一下就被唬住 → 温和停 3 秒让孩子先凭直觉选（选项照 `choices`，如事实/观点/都有 或 真/假/说不清）→ 咕咕博士和伙伴边聊边查 3 条线索（**绝不念“第一、第二、第三”**），团子狗恍然大悟 → 提醒把页面倒过来看结论。不剧透答案，不说教 |
| 经典连载（≤ 20 句）| 旁白（随章节情绪变化）+ 认领成员 + 波波鼠 | **情绪跟着本回内容走**：温情思乡就温柔细腻，探险追逐才紧凑有张力；书中对白交给认领成员（或单旁白先点出谁在说）→ 波波鼠慢速念原著金句，旁白温润道出中文意思 → 跳出故事，旁白轻巧引出 `crew.who` 本人发出真情吐槽或感慨 → 念 `guess`，停 3 秒留足回味。周五音乐盒/放映室/动手做：主持成员像好朋友推荐宝藏一样自然介绍、讲清任务或步骤 |
| 周末思辨（周五，≤ 14 句）| 旁白 + 两位成员 | 旁白温和讲出生活小故事 → 两位成员各自诚恳说出自己的想法、轻轻松松讨论一两句 → 旁白念「换你来」停 3 秒 → 念一个追问 → 邀请孩子写下想法、周末和家人一起聊。不给标准答案 |
| 信箱（≤ 10 句，最后一页）| 团子狗 + 全员 | 亲切念 `hello`（接住孩子上期的话或分享一件小趣事）→ 轻松聊起本期 `blunder` 的可爱小迷糊，当事伙伴不好意思地解释、大家善意笑闹几句 → 念出树洞好玩提问（`treehole.question` + `treehole.hint`），停 3 秒 → 提醒孩子写/画下来讲给 `send_note` 里的人听 → 两三位伙伴温暖接力道别，送上一个明天的新期待（不重复小剧场 `tbc`）。绝不念 5 个旧版机械问卷、不出猜谜、不公布上期答案 |

## 其他规矩

- **不念答案**：封面答案由今日一问讲；谜题、真的假的答案倒印在本页底部；信箱不公布上期答案
- 补充的事实、数字和页面、来源一致；不念来源、照片署名、页码
- 年份、日期不念；数字只留主线那一个，写成中文读法（“7%”写“百分之七”，“18.5 公斤”写“十八点五公斤”）
- 每句 ≤ 30 字或 ≤ 12 个英文词，长句拆成自然口语短句、分给不同伙伴接
- 一个角色最多连说 3 句就换人；接话多用温暖自然的口语（“哎你看”“原来是这样呀”“慢着”“哇，真有意思”），角色之间自然互叫名字；全期“等等”最多 1 处
- 页与页之间不写生硬串词，页中间删掉“好啦”“那么”“接下来”“让我们一起”等播音腔填充词
- `pause` 一般不写，交给 video 步骤按对话节奏自动定；只在要孩子想一想或悬念处写，每页最多一处 ≥ 3 秒
- 全期约 1800–2800 字（若本期收敛为 6 页左右，同样把重点栏目聊透，落在 1800–2500 字左右最舒服）

## 自检

`node scripts/pipeline.mjs check <issue>` 没有 `[narration]` 报错，再像听众一样默念一遍确认五件事：
- 每页的 `thread` 讲透了，没有多余枝蔓
- 听感温暖友好：没有老师说教味、没有“第一第二第三”清单腔、没有“XX先放一放”硬转场、也没有刻薄互怼或强行大呼小叫
- 每页至少有一个自然的反应回合，且英文词是在聊天里自然接住的，不是机械点名
- 闭眼听：每句提到的人、东西、画面前面都交代过，不看图也完全听得懂
- 逐句看相邻两句：每一句都顺着上一句的话头往下接，读起来顺口、有呼吸感

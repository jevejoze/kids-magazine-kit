# 09 传说怪物档案

**目标**：每周一（自然科学日）一张可收集的怪物卡，排在今日一问后面。一张卡讲一只传说怪物：传说里怎么说、科学家怎么说、它的真实原型是什么。编号从 No.001 往上排，孩子攒成一本档案。其他日子不出（`00-brief.json` 的 `creature` 为 `false` 时这一步跳过）。

**读**：`issue/00-brief.json`（`creature`）、`data/creature-log.md`（已经发过哪些、下一个编号）、`data/profile.md`（兴趣）

**写**：`issue/09-creature.json`

```json
{
  "_meta": {"stage": "09-creature", "by": "", "at": ""},
  "no": 1,
  "name_zh": "大海蛇",
  "parts": [{"en": "Sea", "zh": "海"}, {"en": "Serpent", "zh": "大蛇"}],
  "photo_url": "https://commons.wikimedia.org/wiki/File:Regalecus_glesne_Mexico.jpg",
  "photo_credit": "Katia Cao · CC BY 3.0",
  "photo_pos": "center 45%",
  "tag": "🌊 浅海到 1000 米",
  "stats": [{"k": "传说身长", "v": "60 米"}, {"k": "真实原型", "v": "皇带鱼"}, {"k": "原型身长", "v": "最长 8 米"}],
  "meters": [{"label": "吓人", "n": 4, "icon": "😱"}, {"label": "真实", "n": 3, "icon": "🔍"}, {"label": "罕见", "n": 5, "icon": "💎"}],
  "boxes": [
    {"title": "📜 传说里说", "text": "≤ 60 字"},
    {"title": "🔬 科学家怎么说", "text": "≤ 60 字"},
    {"title": "🐟 真实原型", "text": "≤ 60 字"}
  ],
  "fast": "一定是真的大海蛇！",
  "slow": "先看看有没有被抓到过的标本？",
  "sources": ["博物馆或科研机构页面", "另一个独立来源"],
  "log_update": "No.001 大海蛇 → 皇带鱼"
}
```

**规则**
- 选题：按 `profile.md` 的兴趣挑；默认是海里的传说怪物（大海蛇、克拉肯、美人鱼、尼斯湖水怪、利维坦……），每只都要有一个科学上说得清的真实原型（皇带鱼、大王乌贼、儒艮、鳗鱼……）。`creature-log.md` 里发过的不重复
- `no` 接 `creature-log.md` 的最后一个编号 + 1
- `name_zh` ≤ 8 字；`parts` 把英文名拆成 1–3 个词，每个配中文意思（孩子顺便认词）
- **照片拍真实原型**：一张自由授权的实拍照片（Commons、NOAA、博物馆开放图库），一眼看得出是什么动物；`photo_credit` 写作者和协议。传说怪物没有真照片，古画、版画只在原型实在没有照片时用，并在 `_meta.issues` 写明
- `tag` 一句栖息地或深度（≤ 12 字）；`stats` 3 格，固定一格写传说里的数字、一格写原型、一格写原型的真实数字
- `meters` 2–3 条打分（1–5），吓人程度、真实程度、罕见程度，或者换成和这只怪物有关的维度
- `boxes` 3 格，顺序固定：传说里说 → 科学家怎么说 → 真实原型，各 ≤ 60 字。"科学家怎么说"讲人们是**怎么查出来的**（标本、照片、目击误认），让孩子看到证据怎么推翻传说
- `fast`、`slow` 各 ≤ 24 字：团子狗的快脑袋一下子信了，咕咕博士的慢脑袋提一个查证的问题，和「真的假的」用同一套说法
- 传说里吞船、吃人这类情节一句带过，写成好笑或神秘的样子；不写血腥、恐怖画面
- `sources` 至少 2 个独立来源，科学事实都要查得到；`log_update` 是第 90 步追加到 `creature-log.md` 的一行

**自检**：编号接得上；照片拍的是原型、授权写清；3 格字数；`stats` 和 `boxes` 里的数字和来源一致

# 50 讲读稿

**目标**：把这一期写成一档 10–12 分钟的儿童电台节目。孩子只听、不看字，也能听懂、听得进去，听起来像几个朋友在聊天。

**读**：`issue/30-issue.json`、`issue/31-review.md`（确认已通过）、`issue/10-cover.json`（照片的来历）、`issue/11-comic.json` 的 `sources`、`issue/13-story.json`、`issue/17-news.json`（`talk`、`photo_shows`）、`issue/18-serial.json`、`data/serial-bible.md`（角色认领、连载由谁念）、`data/profile.md`（称呼、选定的声音）、SKILL.md「讲读版」一节

**写**：`issue/50-narration.json`

```json
{"_meta": {"stage": "50-narration", "by": "", "at": "", "content_hash": "<当前内容指纹>"},
 "narration": [{"card": 1, "thread": "半夜十二点的太阳，团子困得要命", "lines": [
   {"who": "narrator", "lang": "zh", "text": "……", "emotion": "开心", "sfx": "chime"}
 ]}]}
```

写稿前运行 `node scripts/pipeline.mjs fingerprint <issue>`，把指纹放进 `_meta.content_hash`。必须先确认审稿通过且指纹有效；内容变化后重写对应台词并更新指纹，不能直接给旧稿换指纹。

`card` 按渲染出来的页面顺序编号：封面 1、今日一问 2、怪物档案（周一才有）、单词屋（做了才有）、小剧场、挑战、环球小报、真的假的、经典连载、周末思辨（周五才有）、信箱（最后一页）。平时 1–8，周一、周五 1–9。

每句的字段：`who` `lang` `text` `emotion`（中文句必填）`sfx` `pause` `repeat` `rate` `hold` `pron`，取值见 SKILL.md「讲读版」。每页另写一个 `thread`：这一页要让孩子记住的那一件事，≤ 30 字，只给写稿用，不念出来。

## 写稿顺序（每页都照这五步走）

1. **定主线**：先写 `thread`。一页只讲透这一件事，页面上和主线无关的细节（星级、日期、第二个数字）一律不讲。
2. **排角色**：照下面「每页怎么讲」的表，定好谁主持、谁捣乱、谁收尾。
3. **写骨架**：每页至少有一个**反应回合**——有人猜错、误会、不服气或吓一跳，另一个角色接住、纠正或逗回去。团子狗是天然的猜错者；浣熊是天然的嘴硬者。
4. **写台词**：叙述归旁白，说话归角色；用口语重新说页面内容，不照着页面念。
5. **删一遍、跑检查**：从头念一遍，删掉重复的、客套的、只把上一句换个说法的句子；然后跑 `node scripts/pipeline.mjs check <issue>`，有报错就改到没有为止。

## 七条硬规矩（脚本会查）

| # | 规矩 | 查法 |
|---|---|---|
| 1 | 角色不说自己的名字，不用第三人称讲自己的动作 | 角色台词里出现自己的名字就报错（"我是团子狗"除外） |
| 2 | 旁白只负责开场、串词、交代场景和动作 | 除连载页外，旁白占全期句数 ≤ 40%，单页 ≤ 60% |
| 3 | 语气要有起伏 | 中文句都写 `emotion`；全期"平静" ≤ 40% |
| 4 | 不照着页面念 | 今日一问、怪物档案、小剧场、环球小报、连载、周末思辨：和页面叙述文字连续 10 个字相同的句子，每页最多 2 句或全页的四分之一。角色对白（引号里的话）、要孩子回答的问题不算 |
| 5 | 同一件事只说一遍 | 同一页里两句有连续 8 个字相同就报错 |
| 6 | 串词每页换花样 | "看完了 / 讲完了 / 做完 / 弄懂了"这类收尾式串词全期最多 2 处 |
| 7 | 不说答案在哪一期公布 | 挑战页不说"答案明天见 / 信箱里见"（答案倒印在本页底部）；信箱不念上期答案 |

另外还查：每页 `thread`、句数上限、每句 ≤ 30 字或 ≤ 12 个英文词、同一角色最多连说 3 句、每页 ≥ 3 秒的停顿最多一处、中文里不写阿拉伯数字、总字数。

## 写法：错的和对的

**① 叙述和对白分开**
- ❌ `mouse`：波波鼠把全家福翻了个面，背面还有一行小字！
- ✅ `narrator`：波波鼠把全家福翻了过来。 → `mouse`：Look! 背面还有字！

**② 用反应代替问答**（团子狗猜错，别人接住）
- ❌ `dog`：那河水为啥不咸呢？ → `owl`：河水不停流，盐攒不起来。
- ✅ `dog`：我知道！河里的鱼把盐吃光了！ → `owl`：哈，鱼可不吃盐。盐是雨水从石头里冲出来的。

**③ 知识由懂的人说，团子狗负责惊讶**
- ❌ `dog`：哈哈，一升海水里有三十五克盐呢！
- ✅ `owl`：一升海水里，有三十五克盐。 → `dog`：三十五克是多少？ → `narrator`：差不多两大勺，倒进两瓶矿泉水里。

**④ 数字少而落地**：一页只讲一个数字，紧跟一个孩子摸得着的比较（几大勺、几辆公交车、开车多久）。年份、日期、第二个尺寸都删。

**⑤ 英文走完一个来回**：波波鼠说一句 3–8 个词的完整短句 → 团子狗听不懂、学舌或误会 → 有人一句中文接住。
- ❌ `mouse`：wildcat!
- ✅ `mouse`：A brand-new wildcat! → `dog`：外……外什么猫？ → `owl`：wildcat，野猫。

**⑥ 不复述事实来提问**
- ❌ `dog`：二零零四年，人们第一次拍到了活的大王乌贼？
- ✅ `owl`：直到二零零四年，才有人拍到活的。 → `dog`：这么难找？它躲哪儿去了！

**⑦ 只有一个声音念时，先点出是谁在说**（`serial-bible.md` 规定连载全部由旁白念时）
- ❌ `narrator`：快来看！这才是真正的生活！
- ✅ `narrator`：蟾蜍一挥手，大声嚷嚷：快来看！这才是真正的生活！

**⑧ 串词接住上一页的一个具体细节**
- ❌ 新闻看完了，我们来看看下一页。
- ✅ 说到会敲门的鹈鹕——网上还有一条更离谱的视频。团子，你先看！

## 每页怎么讲

| 页 | 主持 | 骨架 |
|---|---|---|
| 封面（≤ 12 句）| 旁白开场，封面成员 | 开场铃 + 一句问候（叫孩子的名字、今天什么主题日）→ 封面上的 1–2 位成员抢一句和主题有关的俏皮话 → 两三句讲照片最奇怪的地方（拍摄时间、地点本身就是证据）→ 团子狗提出问题 → 停 5 秒让孩子猜。不说答案 |
| 今日一问（≤ 26 句）| 咕咕博士 + 团子狗 | 团子狗先猜一个错的答案 → 咕咕博士讲机制，用一个生活里的类比（传送带、手电筒照地球仪）→ 团子狗至少插嘴两次（"等等，那……"）→ 一个数字，讲慢一点、配比较 → 波波鼠一句英文总结，有人接 → "你也可以试试"最多一句 |
| 怪物档案（周一，≤ 14 句）| 咕咕博士像博物馆讲解员 | 用 `神秘` 语气讲传说，描述左边古人画的样子 → 团子狗吓一跳 → 科学家怎么查出来的（一条证据）→ 揭晓真实原型，描述右边照片，比一比哪里被夸张了 → 波波鼠用一句短句念英文名。星级、编号不念 |
| 小剧场（≤ 30 句）| 旁白 + 四位成员 | 像广播剧：旁白一句交代场景、加拟声词和 `sfx`；原文里引号中的对白由说话的角色演，原文的叙述由旁白用短句说；紧张处放慢 → 旁白念侦探笔记，停 5 秒 → 结尾用 `神秘` 语气 |
| 挑战（≤ 12 句）| 捣蛋浣熊 | 浣熊一句挑衅 → 浣熊和旁白分着把条件念清楚 → 团子狗想偷懒或乱猜一个，被浣熊"哼"回去 → 一句思路提示 → 提醒想好后转动平板看本页底部答案 |
| 环球小报（≤ 24 句）| 旁白 + 咕咕博士 | 头条 8–10 句：先描述照片里看到了什么（`photo_shows`）→ 用 `talk` 讲在哪、发生了什么、怎么发现的 → 一个尺度类比 → 接到孩子身上。两条短讯各 4–5 句，各有一个角色的反应。关键词由波波鼠放进一句短句里说 → 念"你怎么看" |
| 真的假的（≤ 12 句）| 旁白 + 团子狗 + 咕咕博士 | 旁白用刷视频的口气念说法 → 团子狗的快脑袋马上信了 → 停 3 秒让孩子选 → 咕咕博士带着念 3 条线索，团子狗在中间插一句 → 提醒孩子把页面倒过来看答案。不念答案 |
| 经典连载（≤ 20 句）| 旁白（睡前故事的语气）| 串词 → 把这一回讲出来，书中角色的对白交给认领他的成员念；`serial-bible.md` 规定全部由旁白念时，每句对白前先点出是谁说的 → 波波鼠慢速念原著金句，旁白一句中文意思 → 认领的成员吐槽一句（`crew.say`）→ 念"猜一猜"，停 3 秒。周五：主持的成员两三句介绍这首曲子、这部电影或这件手工，任务或步骤念清楚（折纸只念难的那一两步，提醒"照着图一步步折"） |
| 周末思辨（周五，≤ 14 句）| 旁白 + 两位成员 | 旁白把小故事讲出来 → 两位成员各说自己那边的理由，互相顶一两句 → 旁白念「换你来」，停 3 秒 → 念一个追问 → 提醒"先写下你的想法，周六和家人聊一聊"。编辑部不给结论 |
| 信箱（≤ 10 句，最后一页）| 团子狗 + 全员 | 念 `hello` → 一两句带过 5 个打卡问题（"最喜欢哪页、哪页不喜欢、难不难，还有今天想到的问题、看到的事，都说给妈妈听"）→ 有 `ask_zh` 就念并停 3 秒 → 两三位成员接力道别，一句预告明天（只给一个悬念）|

## 其他规矩

- **不念答案**：封面问题的答案由今日一问讲；谜题、真的假的的答案倒印在本页底部；信箱不公布上期答案
- 补充的事实、数字和页面、来源一致；不念来源、照片署名、页码
- 数字和符号写成读法（"7%"写"百分之七"，"18.5 公斤"写"十八点五公斤"）
- 每句 ≤ 30 字或 ≤ 12 个英文词，长句拆开、分给不同角色接
- 一个角色最多连说 3 句就换人；接话用口语开头（"诶？""对呀！""等等——""哈，被我猜中了"），角色互相叫名字
- 第 2 页起每页一句串词开场：接住上一页的一个具体细节、说清这一页看什么、把话筒交给主持的角色。页中间的"好啦""那么""接下来""让我们一起"删掉
- `pause` 一般不写，交给第 70 步按对话节奏自动定；只在要孩子思考、跟读的地方写，每页最多一处 ≥ 3 秒
- 英文自然融入：波波鼠的台词、新闻关键词、连载金句照常念，不额外加英文教学
- 全期约 1800–2800 字；小剧场、今日一问、环球小报占最多篇幅

## 自检

`node scripts/pipeline.mjs check <issue>` 没有 `[50]` 报错，再人工确认三件事：
- 每页的 `thread` 讲到了，而且全页只讲了这一件事
- 每页至少有一个反应回合（有人猜错、误会或吓一跳，有人接住）
- 只听不看，分得清每句是谁在说

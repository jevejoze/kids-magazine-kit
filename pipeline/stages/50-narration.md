# 50 讲读稿

**目标**：把这一期写成一档 10–12 分钟的儿童电台节目。孩子只听、不看字，也能听懂、听得进去，听起来像几个性格鲜明的好朋友在阁楼工作间里真诚、幽默、热烈地聊天探险。

**读**：`issue/30-issue.json`、`issue/31-review.md`（确认已通过）、`issue/10-cover.json`（照片的来历）、`issue/11-comic.json` 的 `sources`、`issue/13-story.json`、`issue/17-news.json`（`talk`、`photo_shows`）、`issue/18-serial.json`、`data/serial-bible.md`（角色认领、连载由谁念）、`data/profile.md`（称呼、选定的声音）、SKILL.md「讲读版」一节

**写**：`issue/50-narration.json`

```json
{"_meta": {"stage": "50-narration", "by": "", "at": "", "content_hash": "<当前内容指纹>"},
 "narration": [{"card": 1, "thread": "半夜十二点的太阳，团子困得要命", "lines": [
   {"who": "narrator", "lang": "zh", "text": "……", "emotion": "开心", "sfx": "chime"}
 ]}]}
```

写稿前运行 `node scripts/pipeline.mjs fingerprint <issue>`，把指纹放进 `_meta.content_hash`。必须先确认审稿通过且指纹有效；内容变化后重写对应台词并更新指纹，不能直接给旧稿换指纹。

`card` 按渲染出来的页面顺序编号：封面 1、今日一问 2、怪物档案（周一才有）、单词屋（做了才有）、小剧场、挑战、环球小报、真的假的、经典连载、周末思辨（周五才有）、信箱（最后一页）。平时 1–8，周一、周五 1–9。

每句的字段：`who` `lang` `text` `emotion`（中文句必填）`sfx` `pause` `repeat` `rate` `hold` `pron`，取值见 SKILL.md「讲读版」。每页另写一个 `thread`：这一页要让孩子记住的那一件事，≤ 30 字，只给写稿用，不念出来。

## 写稿顺序（每页都照这五步走）

1. **定主线**：先写 `thread`。一页只讲透这一件事，页面上和主线无关的细节（星级、年份、日期、第二个数字）一律不讲。环球小报的 `thread` 要把三条新闻都点到。
2. **排角色**：按阁楼编辑部小伙伴的性格分工，谁挑起好奇、谁做接地气的比喻、谁出难题、谁收尾。
   - **团子狗**：儿童生活经验的天然代言人（爱吃、爱睡、怕黑、想偷懒贪玩、爱钻大人规则的空子）。他的幽默来自儿童的真实直觉，绝不是装傻装蠢！
   - **咕咕博士**：博学又接地气的老顽童。擅长拿身边的碗、陀螺、西瓜打生活比喻，讲到兴起会手舞足蹈，被小家伙们逗乐时也大方认输。
   - **捣蛋浣熊**：机灵好胜的小淘气，爱挑战、爱打赌、爱出难题，但心底仗义热心。
   - **波波鼠**：活力满满的双语小达人。英文是她脱口而出的自然感叹与情境短句，同伴顺着语境自然接话，绝不搞死板的查字典翻译。
   - **旁白**：温暖的说书人兼气氛营造师，用富有画面感的声音带着孩子的耳朵去“看”，串词靠动作与情绪转场，绝不机械报幕。
3. **写骨架**：先用一行一句列出这一页的"谁 → 做什么"，再填台词。每页至少有一个**真实对话回合**——打破脸谱化套路，由真实的好奇、碰撞、启发推进剧情。
4. **写台词**：叙述归旁白，说话归角色；用鲜活的儿童口语重新说，不照着页面念。
5. **闭眼听一遍、跑检查**：假装自己看不到页面，从头念一遍——每句提到的东西前面都交代过吗？相邻两句接得上吗？删掉重复的、客套的、只把上一句换个说法的句子；然后跑 `node scripts/pipeline.mjs check <issue>`，有报错就改到没有为止。

## 硬规矩（脚本会查）

| # | 规矩 | 查法 |
|---|---|---|
| 1 | 角色不说自己的名字，不用第三人称讲自己的动作 | 角色台词里出现自己的名字就报错（"我是团子狗"除外） |
| 2 | 旁白只负责开场、串词、交代场景和动作 | 除连载页外，旁白占全期句数 ≤ 40%，单页 ≤ 60% |
| 3 | 语气要有起伏 | 中文句都写 `emotion`；全期"平静" ≤ 40% |
| 4 | 不照着页面念 | 今日一问、怪物档案、小剧场、环球小报、连载、周末思辨：和页面叙述文字连续 10 个字相同的句子，每页最多 2 句或全页的四分之一。角色对白（引号里的话）、要孩子回答的问题不算 |
| 5 | 同一件事只说一遍 | 同一页里两句有连续 8 个字相同就报错 |
| 6 | 串词每页换花样 | "看完了 / 讲完了 / 做完 / 弄懂了"这类收尾式串词全期最多 2 处 |
| 7 | 不说答案在哪一期公布 | 挑战页不说"答案明天见 / 信箱里见"（答案倒印在本页底部）；信箱不念上期答案 |
| 8 | 一页一个数字 | 带单位的数字（三十五克、四十六厘米、一百小时）每页最多 1 个，环球小报每条新闻 1 个、整页最多 3 个；同一个数字说两遍只算一个。小剧场、挑战、连载不查 |
| 9 | 不念年份和日期 | "二零零九年""十月十九日"这类一律删；要说时间就说"十几年前""上个星期" |
| 10 | 不照抄本文件的例句 | 和下面「写法：错的和对的」里的句子连续 8 个字相同就报错。例句只示范句子怎么搭，话题故意和任何一期都无关 |
| 11 | 环球小报三条都讲到 | 每条新闻的关键词 `word.en` 都要在波波鼠的英文句里出现 |
| 12 | 今日一问以"你也可以试试"收尾 | 说了"试试"之后最多再有一句 |
| 13 | 信箱说给对的人 | "说给 / 发给 / 告诉某某"要和 `send_note` 里的人一致；明天的预告不重复小剧场的 `tbc` |
| 14 | 英文走完一个来回 | 今日一问、怪物档案、环球小报：波波鼠的每句英文后 3 句内，要有同伴在中文句里带上其中一个核心英文词（如"volcano，火山"），顺着语境自然接话。只说中文意思或生硬背词典不算 |
| 15 | 先交代再提起 | 角色的问句和同页后面旁白的交代有连续 4 个字相同就报错：旁白的交代挪到问句前面 |
| 16 | 连载吐槽由认领的成员自己说 | 连载页（`kind: "book"`）要有 `crew.who` 那个角色的台词；旁白只用一句引出，不替他念 |
| 17 | 信箱不出猜谜 | 信箱页不说"你猜"；`hello` 里重问封面问题的半句略过 |

另外还查：每页 `thread`、句数上限、每句 ≤ 30 字或 ≤ 12 个英文词、同一角色最多连说 3 句（连载页由旁白一人念时除外）、每页 ≥ 3 秒的停顿最多一处、中文里不写阿拉伯数字、总字数。

## 写法：错的和对的

下面的例子只示范**句子怎么搭**。话题（章鱼、蜂鸟、火山、企鹅……）故意选得和任何一期都无关；写稿时照这个结构，用这一期自己的内容重新造句，例句里的词句一句都不要搬。

**① 叙述和对白分开**
- ❌ `mouse`：波波鼠把信封倒过来，抖出一片羽毛！
- ✅ `narrator`：波波鼠把信封倒过来抖了抖。 → `mouse`：Look! 一片羽毛！

**② 用生活直觉与真实反应代替干瘪问答**
- ❌ `dog`：企鹅的脚为啥不冻僵？ → `owl`：脚上的血管会互相取暖。
- ✅ `dog`：我知道！企鹅偷偷穿了袜子！ → `owl`：哈，哪来的袜子。它脚上的血管会互相取暖。

**③ 知识由懂的人说，同伴负责真实的生活共鸣与追问**
- ❌ `dog`：哈哈，蜂鸟的心一分钟跳一千多下呢！
- ✅ `owl`：蜂鸟的心，一分钟跳一千多下。 → `dog`：一千多下？那得多累啊！ → `narrator`：你的心一分钟才跳八十来下。

**④ 数字少而落地**：一页只讲一个数字，紧跟一个孩子摸得着的比较（几大勺、几辆公交车、开车多久、自己的心跳）。年份、日期、第二个尺寸、"是那个的十倍"这类第二个数字都删。

**⑤ 英文走完一个来回**：波波鼠说一句 3–8 个词的完整短句 → 同伴顺着语境把那个英文词自然带入中文对话，不机械学舌，不背诵查词典：
- ❌ `mouse`：Volcano, a fire mountain! → `dog`：记住了，火山！
- ❌ `mouse`：The volcano is waking up! → `dog`：喔……喔什么诺？ → `owl`：volcano 就是火山。
- ✅ `mouse`：The volcano is waking up! → `dog`：等等，volcano？火山醒了？那地底下岂不是像爆米花噼里啪啦！ → `owl`：没错，滚烫的岩浆随时要喷出来了！

**⑥ 不复述事实来提问**
- ❌ `dog`：章鱼真的有三颗心吗？
- ✅ `owl`：章鱼有三颗心。 → `dog`：三颗？那它谈恋爱是不是特别容易！

**⑦ 只有一个声音念时，先点出是谁在说**（`serial-bible.md` 规定连载全部由旁白念时）
- ❌ `narrator`：今晚谁也别想睡觉！
- ✅ `narrator`：老船长一拍桌子，瞪着眼睛说：今晚谁也别想睡觉！

**⑧ 串词接住上一页的一个具体细节（用动作、情绪或现场道具转场，拒绝报幕腔）**
- ❌ 新闻看完了，我们来看看下一页。
- ❌ 说到不睡觉的太阳，我们来看今天的挑战。
- ✅ 刚才那只会开门的章鱼——网上有人说它还会偷看电视。团子，你信吗？
- ✅ 别顾着啃骨头啦，快把桌上的大地图摊开！

**⑨ 只听也跟得上：先交代，再提起**
- ❌ `dog`：会不会是那把钥匙开的？（前面没人说过有钥匙）
- ✅ `narrator`：团子狗从口袋里掏出一把小钥匙。 → `dog`：会不会是这把开的？

**⑩ 每句接住上一句**：后一句要回应、追问、解释或推进前一句。两句之间得补一句"所以 / 可是 / 那为什么"才连得上，就把这一步补出来，或者删掉其中一句。各说一个事实、互不相干的两句，只听的孩子接不上
- ❌ `narrator`：这张照片是几年前在海边拍的。 → `owl`：这座山底下全是滚烫的岩浆！
- ✅ `dog`：咦，山顶上怎么白白的？ → `owl`：那是雪。这座山其实是一座火山。 → `dog`：火山不是烫得冒火吗？雪怎么不化？
- 页面上一眼看得到的东西（谁拿着什么、纸条上写了什么、画是谁画的），讲读里要先用一句交代，后面才能提。按原文改编成广播剧时，猜测要放在被纠正之前：先有人提议"去花园找"，再有人说"花园里没有"。

## 每页怎么讲

| 页 | 主持 | 骨架 |
|---|---|---|
| 封面（≤ 12 句）| 旁白开场，封面成员 | 开场铃 + 一句亲切问候（叫孩子的名字、今天什么主题日）→ 封面成员抢着发现照片里的古怪细节（看到了什么 → 哪里怪 → 产生悬念）→ 团子狗抛出封面核心问题 → 停 5 秒让孩子猜。不说答案 |
| 今日一问（≤ 26 句）| 咕咕博士 + 团子狗 | 团子狗从真实儿童生活直觉切入（如"那我不就不用睡觉了？"）→ 咕咕博士用生动动作或生活实物类比（端歪的汤碗、转陀螺、手电筒照地球仪）讲透机制 → 团子狗带着好奇往深处追问 → 一个硬核数字慢讲配身边比较 → 波波鼠英文自然感叹，同伴顺着英文词自然接话 → 最后一句"试试"亲自动手结尾 |
| 怪物档案（周一，≤ 14 句）| 咕咕博士像博物馆讲解员 | 用 `神秘` 语气讲古老传说，描述古人画出的神奇怪兽 → 团子狗既兴奋又好奇 → 科学家怎么查出来的（关键证据）→ 揭晓真实原型，比一比大自然哪里比想象更奇妙 → 波波鼠用一句短句念英文名。星级、编号不念 |
| 小剧场（≤ 30 句）| 旁白 + 四位成员 | 像广播剧：旁白交代场景、加拟声词和 `sfx`；先把原文拆成"一个动作一行"，按原文顺序排；紧张处放慢，角色互相打趣、指认现场物证，把紧张又搞笑的气氛做足 → 旁白念出清晰聚焦的侦探笔记，停 5 秒 → 悬念收尾 |
| 挑战（≤ 12 句）| 捣蛋浣熊 | 浣熊神气活现地下战书 → 旁白和浣熊如双簧般分着把条件念清楚 → 团子狗想投机取巧被当场抓包 → 咕咕博士点出关键思维切入点（"先抓最确定的人"）→ 提醒想好后转动平板看本页底部答案 |
| 环球小报（≤ 24 句）| 旁白 + 咕咕博士 | 头条像讲身边厉害的小伙伴（神童自学传奇）→ 用 `talk` 讲地点、发生经过与尺度类比 → 接到孩子身上。两条短讯像讲世界各地的奇趣探险，每条由波波鼠自然感叹说出关键词（`word.en`），同伴顺着词接话 → 念一道启发思考的"你怎么看" |
| 真的假的（≤ 12 句）| 旁白 + 团子狗 + 咕咕博士 | 营造刷到离谱热门短视频的现场感 → 团子狗的第一反应 vs 咕咕博士带大家像侦探一样抽丝剥茧查 3 条线索 → 提醒孩子把页面倒过来看裁决结论。不念答案 |
| 经典连载（≤ 20 句）| 旁白（睡前故事的语气）| 动作或细节转场 → 睡前故事氛围，把这一回娓娓道来；波波鼠慢速深情念原著金句，旁白一句中文意思 → 跳出故事，认领的成员在故事外围真诚吐槽（`crew.say`）→ 念"猜一猜"，停 3 秒。周五：主持成员两三句介绍曲子、电影或手工，步骤念清楚 |
| 周末思辨（周五，≤ 14 句）| 旁白 + 两位成员 | 旁白把小故事讲出来 → 两位成员各说自己那边的生活理由，互相争论 → 旁白念「换你来」，停 3 秒 → 念一个追问 → 提醒"先写下你的想法，周六和家人聊一聊"。编辑部不给结论 |
| 信箱（≤ 10 句，最后一页）| 团子狗 + 全员 | 像电台节目的温馨收官：接住前面小剧场或封面的趣味彩蛋 → 一两句带过打卡问题，交代说给 `send_note` 里的那个人听 → 有 `ask_zh` 就念并停 3 秒 → 成员们接力道别，留一个明日悬念 |

## 其他规矩

- **不念答案**：封面问题的答案由今日一问讲；谜题、真的假的的答案倒印在本页底部；信箱不公布上期答案
- 补充的事实、数字和页面、来源一致；不念来源、照片署名、页码
- 年份、日期不念；数字只留主线那一个，和页面一致
- 数字和符号写成读法（"7%"写"百分之七"，"18.5 公斤"写"十八点五公斤"）
- 每句 ≤ 30 字或 ≤ 12 个英文词，长句拆开、分给不同角色接
- 一个角色最多连说 3 句就换人；接话用口语开头（"诶？""对呀！""等等——""哈，被我猜中了"），角色互相叫名字
- 第 2 页起每页一句串词开场：接住上一页的一个具体细节、说清这一页看什么、把话筒交给主持的角色。页中间的"好啦""那么""接下来""让我们一起"删掉
- `pause` 一般不写，交给第 70 步按对话节奏自动定；只在要孩子思考、跟读的地方写，每页最多一处 ≥ 3 秒
- 英文自然融入：波波鼠的台词、新闻关键词、连载金句照常念，不额外加英文教学
- 全期约 1800–2800 字；小剧场、今日一问、环球小报占最多篇幅

## 自检

`node scripts/pipeline.mjs check <issue>` 没有 `[50]` 报错，再人工确认三件事：
- 每页的 `thread` 讲到了，而且全页只讲了这一件事
- 每页至少有一个真实对话回合（打破脸谱化套路，由真实的好奇与碰撞推进）
- 只听不看，分得清每句是谁在说
- 闭眼听：每句提到的人、东西、事情，前面都交代过；没有一句要看着页面才懂
- 逐句看相邻两句：后一句回应、追问或解释了前一句；接不上的补一步或删掉

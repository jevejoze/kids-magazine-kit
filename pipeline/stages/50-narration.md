# 50 讲读稿

**目标**：把这一期写成一档 10–12 分钟的儿童电台节目。孩子只听、不看字，也能听懂、听得进去，听起来像几个朋友在聊天。

**读**：`issue/30-issue.json`、`issue/31-review.md`（确认已通过）、`issue/10-cover.json`（照片的来历）、`issue/11-comic.json` 的 `sources`、`issue/13-story.json`、`issue/17-news.json`（`talk`、`photo_shows`）、`issue/18-serial.json`、`data/serial-bible.md`（角色认领、连载由谁念）、`data/profile.md`（称呼、选定的声音）、SKILL.md「讲读版」一节

**写**：`issue/50-narration.json`

```json
{"_meta": {"stage": "50-narration", "by": "", "at": "", "content_hash": "<当前内容指纹>", "ticket": "<任务单指纹>"},
 "narration": [{"card": 1, "thread": "半夜十二点的太阳，团子困得要命", "lines": [
   {"who": "narrator", "lang": "zh", "text": "……", "emotion": "开心", "sfx": "chime"}
 ]}]}
```

写稿前运行 `node scripts/pipeline.mjs fingerprint <issue>`，把指纹放进 `_meta.content_hash`；再领任务单 `node scripts/pipeline.mjs ticket <issue> narration`，单上的指纹放进 `_meta.ticket`。必须先确认审稿通过且指纹有效；内容变化后重写对应台词并更新指纹，不能直接给旧稿换指纹。

`card` 按本期实际出的栏目编号，不固定哪个栏目排第几页：领任务单（`node scripts/pipeline.mjs ticket <issue> narration`）时「本期骨架」一节已经按这期实际页序列好每页的卡号、句数上限（已按本期页数缩放）和那个栏目自己的 `narrate.md`，照着写就行，不用去猜周一、周五多哪一页。

每句的字段：`who` `lang` `text` `emotion`（中文句必填）`sfx` `pause` `repeat` `rate` `hold` `pron`，取值见 SKILL.md「讲读版」。每页另写一个 `thread`：这一页要让孩子记住的那一件事，≤ 30 字，只给写稿用，不念出来。

## 写稿顺序（每页都照这五步走）

1. **定主线**：先写 `thread`。一页只讲透这一件事，页面上和主线无关的细节（星级、年份、日期、第二个数字）一律不讲。环球小报的 `thread` 要把三条新闻都点到。
2. **排角色**：照下面「每页怎么讲」的表，定好谁主持、谁捣乱、谁收尾。编辑部四位伙伴性格各不相同，让孩子一听就知道是谁（对齐 SKILL.md）：
   - **团子狗**：憨憨的童声、慢一点，爱打哈欠；负责猜错、误会、惊讶与追问，生活直觉丰富；不用"等等"当口头禅（换用"咦？""慢着！""不对呀！"），完全不懂英文，不替别人翻译英文单词
   - **咕咕博士**：沉稳的男声，讲到关键处放慢；负责讲清机制与破案推理，善用生活实物做比喻；解释英文释义，讲动手实验时不提前说破结果
   - **捣蛋浣熊**：调皮、语气夸张，爱"哼"；负责挑衅、嘴硬、出谜题和捣乱，但不是真使坏，被拆穿了也会不好意思
   - **波波鼠**：英式英语小女孩，语速自然；自然穿插地道英文短句，带出核心生词
   - **旁白**：温暖、像讲睡前故事的女声；负责开场、串词、交代场景与动作
3. **写骨架**：先用一行一句列出这一页的"谁 → 做什么"，再填台词。每页至少有一个**反应回合**——有人猜错、误会、不服气或吓一跳，另一个角色接住、纠正或逗回去。团子狗是天然的猜错者；浣熊是天然的嘴硬者。
4. **写台词**：叙述归旁白，说话归角色；用口语重新说页面内容，不照着页面念。
5. **闭眼听一遍、跑检查**：假装自己看不到页面，从头念一遍——每句提到的东西前面都交代过吗？相邻两句接得上吗？删掉重复的、客套的、只把上一句换个说法的句子；然后跑 `node scripts/pipeline.mjs check <issue>`，有报错就改到没有为止。

## 硬规矩（脚本会查）

全期共用的规矩都在这里查（旁白占比、语气、字数、总长……）；第 7、11、12、13、16、17 条是某一页专属的规矩，脚本实际是调用那个栏目包自己的 `check.mjs`（`checkNarration`）查的，写法仍按下表。

| # | 规矩 | 查法 |
|---|---|---|
| 1 | 角色不说自己的名字，不用第三人称讲自己的动作 | 角色台词里出现自己的名字就报错（"我是团子狗"除外） |
| 2 | 旁白只负责开场、串词、交代场景和动作 | 除连载页外，旁白占全期句数 ≤ 40%，单页 ≤ 60% |
| 3 | 语气要有起伏 | 中文句都写 `emotion`；全期"平静" ≤ 40% |
| 4 | 不照着页面念 | 今日一问、怪物档案、小剧场、环球小报、连载、周末思辨：和页面叙述文字连续 10 个字相同的句子，每页最多 2 句或全页的四分之一。角色对白（引号里的话）、要孩子回答的问题不算 |
| 5 | 同一件事只说一遍 | 同一页里两句有连续 8 个字相同就报错 |
| 6 | 串词每页换花样 | "看完了 / 讲完了 / 做完 / 弄懂了"这类收尾式串词全期最多 2 处 |
| 7 | 不说答案在哪一期公布 | 挑战页不说"答案明天见 / 信箱里见"（答案倒印在本页底部）；信箱不念上期答案 |
| 8 | 一页一个数字 | 带单位的数字（三十五克、四十六厘米、一百小时）每页最多 1 个，环球小报每条新闻 1 个、整页最多 3 个；同一个数字说两遍只算一个。小剧场、挑战、连载不查 |
| 9 | 不念年份和日期 | "二零零九年""十月十九日"这类一律删；要说时间就说"十几年前""上个星期" |
| 10 | 不照抄本文件的例句 | 和下面「写法：错的和对的」里的句子连续 8 个字相同就报错。例句只示范句子怎么搭，话题故意和任何一期都无关 |
| 11 | 环球小报三条都讲到 | 每条新闻的关键词 `word.en` 都要在波波鼠的英文句里出现 |
| 12 | 今日一问以"你也可以试试"收尾 | 说了"试试"之后最多再有一句 |
| 13 | 信箱说给对的人 | "说给 / 发给 / 告诉某某"要和 `send_note` 里的人一致；明天的预告不重复小剧场的 `tbc` |
| 14 | 英文走完一个来回 | 今日一问、怪物档案、环球小报：波波鼠的每句英文后 3 句内，要有别的角色在中文句里说出其中一个英文词（"volcano，火山"）。只说中文意思不算 |
| 15 | 先交代再提起 | 角色的问句和同页后面旁白的交代有连续 4 个字相同就报错：旁白的交代挪到问句前面 |
| 16 | 连载吐槽由认领的成员自己说 | 连载页（`kind: "book"`）要有 `crew.who` 那个角色的台词；旁白只用一句引出，不替他念 |
| 17 | 信箱不出猜谜 | 信箱页不说"你猜"；`hello` 里重问封面问题的半句略过 |

另外还查：每页 `thread`、句数上限、每句 ≤ 30 字或 ≤ 12 个英文词、同一角色最多连说 3 句（连载页由旁白一人念时除外）、每页 ≥ 3 秒的停顿最多一处、中文里不写阿拉伯数字、总字数。

## 写法：错的和对的

下面的例子只示范**句子怎么搭**。话题（章鱼、蜂鸟、火山、企鹅……）故意选得和任何一期都无关；写稿时照这个结构，用这一期自己的内容重新造句，例句里的词句一句都不要搬。

**① 叙述和对白分开**
- ❌ `mouse`：波波鼠把信封倒过来，抖出一片羽毛！
- ✅ `narrator`：波波鼠把信封倒过来抖了抖。 → `mouse`：Look! 一片羽毛！

**② 用反应代替问答**（团子狗猜错，别人接住）
- ❌ `dog`：企鹅的脚为啥不冻僵？ → `owl`：脚上的血管会互相取暖。
- ✅ `dog`：我知道！企鹅偷偷穿了袜子！ → `owl`：哈，哪来的袜子。它脚上的血管会互相取暖。

**③ 知识由懂的人说，团子狗负责惊讶**
- ❌ `dog`：哈哈，蜂鸟的心一分钟跳一千多下呢！
- ✅ `owl`：蜂鸟的心，一分钟跳一千多下。 → `dog`：一千多下？那得多累啊！ → `narrator`：你的心一分钟才跳八十来下。

**④ 数字少而落地**：一页只讲一个数字，紧跟一个孩子摸得着的比较（几大勺、几辆公交车、开车多久、自己的心跳）。年份、日期、第二个尺寸、"是那个的十倍"这类第二个数字都删。

**⑤ 英文走完一个来回**：波波鼠说一句 3–8 个词的完整短句 → 团子狗听不懂、学舌或误会 → 有人一句中文接住，**把那个英文词原样说出来再给意思**。团子狗自己报出中文意思、或者接话的人只说中文意思，孩子都听不出英文词对应哪个中文，不算接住。
- ❌ `mouse`：Volcano, a fire mountain! → `dog`：记住了，火山！
- ✅ `mouse`：The volcano is waking up! → `dog`：喔……喔什么诺？ → `owl`：volcano，火山。它要醒啦。
团子狗不懂英文，只负责听不懂、学舌或念歪（"喔什么诺？"）；英文单词的原词与中文释义由咕咕博士或波波鼠说出。

**⑥ 不复述事实来提问**
- ❌ `dog`：章鱼真的有三颗心吗？
- ✅ `owl`：章鱼有三颗心。 → `dog`：三颗？那它谈恋爱是不是特别容易！

**⑦ 只有一个声音念时，先点出是谁在说**（`serial-bible.md` 规定连载全部由旁白念时）
- ❌ `narrator`：今晚谁也别想睡觉！
- ✅ `narrator`：老船长一拍桌子，瞪着眼睛说：今晚谁也别想睡觉！

**⑧ 串词接住上一页的一个具体细节（用动作、情绪或现场道具转场，拒绝报幕腔）**
- ❌ 新闻看完了，我们来看看下一页。
- ❌ 刚才的故事讲完了，接下来看今天的挑战。
- ✅ 刚才那只会开门的章鱼——网上有人说它还会偷看电视。团子，你信吗？

**⑨ 只听也跟得上：先交代，再提起**
- ❌ `dog`：会不会是那把钥匙开的？（前面没人说过有钥匙）
- ✅ `narrator`：团子狗从口袋里掏出一把小钥匙。 → `dog`：会不会是这把开的？

**⑩ 每句接住上一句**：后一句要回应、追问、解释或推进前一句。两句之间得补一句"所以 / 可是 / 那为什么"才连得上，就把这一步补出来，或者删掉其中一句。各说一个事实、互不相干的两句，只听的孩子接不上
- ❌ `narrator`：这张照片是几年前在海边拍的。 → `owl`：这座山底下全是滚烫的岩浆！
- ✅ `dog`：咦，山顶上怎么白白的？ → `owl`：那是雪。这座山其实是一座火山。 → `dog`：火山不是烫得冒火吗？雪怎么不化？
- 页面上一眼看得到的东西（谁拿着什么、纸条上写了什么、画是谁画的），讲读里要先用一句交代，后面才能提。按原文改编成广播剧时，猜测要放在被纠正之前：先有人提议"去花园找"，再有人说"花园里没有"。

## 每页怎么讲

这张表是详细版；每个栏目包自己的 `sections/<id>/narrate.md` 是对应的简要版，领任务单时会自动附在「本期骨架」那一页下面。

| 页 | 主持 | 骨架 |
|---|---|---|
| 封面（≤ 12 句）| 旁白开场，封面成员 | 开场铃 + 一句问候（叫孩子的名字、今天什么主题日）→ 封面上的 1–2 位成员抢一句和主题有关的俏皮话（不用"等等"开头）→ 两三句从照片最奇怪的地方一步步走到封面问题：看到了什么 → 哪里怪 → 所以想问什么，每句都接住上一句；拍摄时间、地点只在它本身就是证据时才说（半夜的太阳要说几点钟）→ 团子狗提出问题 → 停 5 秒让孩子猜。不说答案 |
| 今日一问（≤ 26 句）| 咕咕博士 + 团子狗 | 团子狗先猜一个错的答案 → 咕咕博士讲机制，用一个生活里的类比（传送带、手电筒照地球仪）→ 团子狗至少插嘴两次，追问往下走一层，不把上一个问题换个说法再问；讲动手实验时不提前说破结果 → 一个数字，讲慢一点、配比较 → 波波鼠一句英文总结，咕咕博士接住 → 最后一句"你也可以试试"，说完就翻页 |
| 怪物档案（周一，≤ 14 句）| 咕咕博士像博物馆讲解员 | 用 `神秘` 语气讲传说，描述左边古人画的样子 → 团子狗吓一跳 → 科学家怎么查出来的（一条证据）→ 揭晓真实原型，描述右边照片，比一比哪里被夸张了 → 波波鼠用一句短句念英文名。星级、编号不念 |
| 小剧场（≤ 30 句）| 旁白 + 四位成员 | 像广播剧：旁白一句交代场景、加拟声词和 `sfx`；先把原文拆成"一个动作一行"，按原文顺序排：原文"某某做了什么：「台词」"拆成旁白一句动作 + 角色一句台词，两句都要留，删了动作，后面的台词只听就听不懂（谁举着什么、哪张纸条、谁画的画）；原文先交代的事讲读里也先交代，角色不抢着问旁白还没讲的事；紧张处放慢 → 旁白念侦探笔记（照 13-story.json 的 clue 念），停 5 秒 → 结尾用 `神秘` 语气 |
| 挑战（≤ 12 句）| 捣蛋浣熊 | 浣熊一句挑衅 → 浣熊和旁白分着把条件念清楚 → 团子狗想偷懒或乱猜一个，被浣熊"哼"回去 → 一句思路提示 → 提醒想好后转动平板看本页底部答案 |
| 环球小报（≤ 24 句）| 旁白 + 咕咕博士 | 头条 8–10 句：先描述照片里看到了什么（`photo_shows`）→ 用 `talk` 讲在哪、发生了什么、怎么发现的 → 一个尺度类比 → 接到孩子身上。两条短讯各 4–5 句，各有一个角色的反应、只配一个数字。每条的关键词 `word.en` 由波波鼠放进一句短句里说，走一个英文来回 → 念"你怎么看" |
| 真的假的（≤ 12 句）| 旁白 + 团子狗 + 咕咕博士 | 旁白用刷视频的口气念说法 → 团子狗的快脑袋马上信了 → 停 3 秒让孩子选 → 咕咕博士带着念 3 条线索，团子狗在中间插一句 → 提醒孩子把页面倒过来看答案。不念答案，不提前下结论 |
| 经典连载（≤ 20 句）| 旁白（睡前故事的语气）| 串词 → 把这一回讲出来，书中角色的对白交给认领他的成员念；`serial-bible.md` 规定全部由旁白念时，每句对白前先点出是谁说的 → 波波鼠慢速念原著金句，旁白一句中文意思 → 跳出故事，旁白用一句"讲到这儿，某某忍不住插嘴"引出认领的成员吐槽（`crew.say`）；编辑部成员只在故事外面插嘴，不走进书里的场景 → 念"猜一猜"，停 3 秒。周五：主持的成员两三句介绍这首曲子、这部电影或这件手工，任务或步骤念清楚（折纸只念难的那一两步，提醒"照着图一步步折"） |
| 周末思辨（周五，≤ 14 句）| 旁白 + 两位成员 | 旁白把小故事讲出来 → 两位成员各说自己那边的理由，互相顶一两句 → 旁白念「换你来」，停 3 秒 → 念一个追问 → 提醒"先写下你的想法，周六和家人聊一聊"。编辑部不给结论 |
| 信箱（≤ 10 句，最后一页）| 团子狗 + 全员 | 念 `hello`（`hello` 里又问了封面问题的那半句略过，答案今日一问已经讲过）→ 一两句把 5 个打卡问题自然融入聊天，说给 `send_note` 里的人听，不重复"都说给某某听" → 有 `ask_zh` 就念并停 3 秒 → 两三位成员接力道别，一句预告明天（只给一个悬念，用小剧场 `tbc` 以外的新悬念）|

## 其他规矩

- **不念答案**：封面问题的答案由今日一问讲；谜题、真的假的的答案倒印在本页底部；信箱不公布上期答案
- 补充的事实、数字和页面、来源一致；不念来源、照片署名、页码
- 年份、日期不念；数字只留主线那一个，和页面一致
- 数字和符号写成读法（"7%"写"百分之七"，"18.5 公斤"写"十八点五公斤"）
- 每句 ≤ 30 字或 ≤ 12 个英文词，长句拆开、分给不同角色接
- 一个角色最多连说 3 句就换人；接话用口语开头（"诶？""对呀！""哈，被我猜中了"），角色互相叫名字；全期"等等"最多 1 处
- 第 2 页起每页一句串词开场：接住上一页的一个具体细节、说清这一页看什么、把话筒交给主持的角色。页中间的"好啦""那么""接下来""让我们一起"删掉
- `pause` 一般不写，交给第 70 步按对话节奏自动定；只在要孩子思考、跟读的地方写，每页最多一处 ≥ 3 秒
- 英文自然融入：波波鼠的台词、新闻关键词、连载金句照常念，不额外加英文教学
- 全期约 1800–2800 字；小剧场、今日一问、环球小报占最多篇幅

## 自检

`node scripts/pipeline.mjs check <issue>` 没有 `[50]` 报错，再人工确认三件事：
- 每页的 `thread` 讲到了，而且全页只讲了这一件事
- 每页至少有一个反应回合（有人猜错、误会或吓一跳，有人接住）
- 只听不看，分得清每句是谁在说
- 闭眼听：每句提到的人、东西、事情，前面都交代过；没有一句要看着页面才懂
- 逐句看相邻两句：后一句回应、追问或解释了前一句；接不上的补一步或删掉

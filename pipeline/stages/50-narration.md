# 50 讲读稿

**目标**：把这一期写成一档 8–10 分钟的儿童电台节目，让孩子只听也能听懂、听得进去。要紧凑、像真的在聊天：每页抓一条主线，角色之间你一句我一句地接话。

**读**：`issue/30-issue.json`、`issue/31-review.md`（确认已通过）、`issue/10-cover.json`（照片的来历）、`issue/11-comic.json` 的 `sources`、`issue/13-story.json`、`data/profile.md`（称呼、选定的声音）、SKILL.md「讲读版」一节

**写**：`issue/50-narration.json`

```json
{"_meta": {"stage": "50-narration", "by": "", "at": ""},
 "narration": [{"card": 1, "lines": [
   {"who": "narrator", "lang": "zh", "text": "……", "emotion": "开心", "sfx": "chime"}
 ]}]}
```

每句的字段（`who` `lang` `text` `emotion` `sfx` `pause` `repeat` `rate` `hold`）和每页讲法见 SKILL.md「讲读版」。

**写法要点**
- 开头：开场铃、一句问好（叫孩子的名字、今天什么主题日），封面上的成员抢一句俏皮话，不挨个点名
- 封面：两三句讲照片最奇怪的地方，团子狗提问，停 5 秒让孩子猜
- 今日一问：咕咕博士用一个类比讲机制，团子狗边听边插嘴；数字只讲一个；"你也可以试试"最多一句
- 小剧场：像广播剧，短句快接；英文集演完后，中文只用三四句讲情节（不点破线索）
- 挑战：一句思路提示，不说答案
- 结尾：两三位成员接力道别，一句预告明天
- 第 2–7 页各用一句串词开场：接住上一页、说清这一页看什么、把话筒交给主持的角色；每页换个说法
- 每句 ≤ 30 字或 ≤ 12 个英文单词；一个角色最多连说 3 句；除了开场串词，页中间的"好啦""那么""接下来"这类过渡句删掉
- `pause` 一般不写，交给第 70 步按对话节奏自动定；只在要孩子思考、跟读的地方写，每页最多一处 ≥ 3 秒

**写完后删一遍**：每页从头读一遍，删掉和页面原文重复的话、只是换个说法再说一遍的话、角色之间的客套话。删完通常能少三分之一。

**自检**（`node scripts/pipeline.mjs check <issue>` 会检查后四条）
- 7 页都有，第 1 页有开场、第 2–7 页各有一句串词、第 7 页有结尾
- 没有念出任何答案；补充的事实、数字和页面、来源一致
- 每页句数不超过上限（封面 12、今日一问 26、单词屋 22、小剧场 30、挑战 14、信箱 12、环球小报 18）
- 每句不超长，同一角色没有连说超过 3 句，每页停顿 ≥ 3 秒的地方最多一处
- 总字数在 1600–2400 之间
- 每句的 `who`、`lang`、`emotion` 都是合法值

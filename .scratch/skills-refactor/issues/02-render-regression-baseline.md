**What to build:** 维护者跑一条回归命令，就能把数据目录里全部目录格式的旧期用当前引擎渲染出来，并和基线逐张逐像素比对，报告哪期哪张不一致。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 同一引擎连渲两遍全部旧期，逐像素一致；有浮动（字体、动画、时间戳）先修掉
- [ ] 回归命令支持「出基线」和「和基线比对」两种用法，比对基于解码后的像素，零新依赖
- [ ] 同时比对新旧 assemble 产出的整期 JSON 结构
- [ ] 基线和对比结果只写本地输出目录，kit 测试只用 demo fixture
- [ ] v1 基线建好并记录在本地

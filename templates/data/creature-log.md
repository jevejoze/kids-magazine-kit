# 传说怪物档案

每周一一张怪物卡（第 09 步），编号从 No.001 往上排，孩子攒成一本档案。第 09 步从这里取下一个编号、避开发过的；第 90 步把每张卡的 `log_update` 追加进来。

## 候选

默认是海里的传说怪物，每只都有说得清的真实原型（第 09 步可以自己补）：

| 怪物 | 真实原型 |
|---|---|
| 大海蛇 Sea Serpent | 皇带鱼 |
| 克拉肯 Kraken | 大王乌贼 |
| 美人鱼 Mermaid | 儒艮、海牛 |
| 鲸鱼岛 Aspidochelone（水手把它当成小岛上岸生火）| 浮在海面晒太阳的鲸鱼 |
| 海里的独角兽 | 一角鲸的长牙（中世纪被当成独角兽的角卖）|
| 海魔 Jenny Haniver | 水手把鳐鱼晒干做成的"小怪物" |
| 海和尚 Sea Monk | 大王乌贼或天使鲨 |

# 孩子问卷 · 家长填写

这份问卷由家长填写，用大白话写就行，越具体越好；不知道的先空着，以后想到再补。
agent 每期出刊前都会读它，**只读不改**。孩子的兴趣、价值观、方向由家长决定，agent 负责把它们变成内容。

填完或改完之后，对 agent 说一句：**"孩子问卷更新了，做一次策展"**。

> 写法提示：「喜欢动物」太笼统；「喜欢猫，尤其是橘猫，会模仿猫叫，问过猫为什么会呼噜」就很好用。

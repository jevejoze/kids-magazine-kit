# 讲读版参考音

每个角色一段 5–10 秒的干净录音（wav），只用本人同意的声音。`voices.json` 写每个角色每种语言用哪段：

```json
{"narrator/zh": "narrator.wav", "narrator/en": "narrator.wav",
 "dog/zh": "dog.wav",
 "mouse/zh": "mouse.wav", "mouse/en": "mouse.wav",
 "owl/zh": "owl.wav", "owl/en": "owl.wav",
 "raccoon/zh": "raccoon.wav", "raccoon/en": "raccoon.wav"}
```

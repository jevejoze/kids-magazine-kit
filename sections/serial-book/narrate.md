# 经典连载 · 书 · 讲读

≤ 20 句（任务单 `narration_lines`），旁白用睡前故事的语气。

- 串词 → 把这一回讲出来，书中角色的对白交给认领他的成员念
- `config.md`（旧数据目录是 `serial-bible.md`）规定全部由旁白念时，每句对白前先点出是谁说的
- 波波鼠慢速念原著金句（`rate: slow`），旁白一句中文意思
- 跳出故事，旁白用一句"讲到这儿，某某忍不住插嘴"引出认领的成员吐槽（`crew.say`），由 `crew.who` 那个角色自己说；编辑部成员只在故事外面插嘴，不走进书里的场景
- 念"猜一猜"（`guess`），停 3 秒

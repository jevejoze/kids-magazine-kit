# 今日一问（comic）

4 格漫画 + 一张图解，揭秘怪奇冷知识、身体与极端生活揭秘（核心刺激：我要炫耀给同桌听）。杜绝教科书式的枯燥原理讲解，把反直觉的怪奇机制、极具谈资的社交货币讲透。

## 背景与定位

- 原定位：4 格漫画解释科学原理（易陷入地轴偏角、大气压强等教科书感）。
- 重构后：怪奇冷知识 / 身体与极端生活揭秘（核心刺激：我要炫耀给同桌听）。
- 案例示范：
  - 主题：宇航员在太空放屁会发生什么？
  - 机制：失重状态下气体无法分层，气体乱窜可能触发警报。
  - 原理图：宇航服内部气体流向趣味示意图（杜绝物理受力坐标轴，改为拟人剖面/流程透视）。
  - 社交行动点：试着用吸管吹水杯感受气压，附带“同桌震撼度”话术。

## 开工

1. 领任务单：`node scripts/pipeline.mjs ticket <issue> comic`，照单上的规则、参数、角色槽位写；最后一行指纹写进 `_meta.ticket`。任务单「下游值」里有 `cover.question`，封面问题一改，这一步就过期
2. 读任务书和 `issue/cover.json`（`answer` 是答案要点）
3. 写 `issue/comic.json` 和 `issue/diagram.svg`，字段见同目录 `schema.json`

```json
{
  "_meta": {"stage": "comic", "by": "", "at": "", "ticket": "<任务单指纹>"},
  "theme_icon": "🚀",
  "title_zh": "宇航员在太空放屁，会发生什么？",
  "title_en": "What happens if an astronaut farts in space?",
  "panels": [
    {"title": "好奇抛出", "bubbles": [{"who": "<asker>", "lang": "zh", "text": "……"}], "chars": ["<asker>:surprise:130"]},
    {"bubbles": [{"lang": "zh", "text": "……"}], "chars": ["<expert>:talk:130"]},
    {"bubbles": [{"lang": "zh", "text": "……"}, {"lang": "zh", "text": "……"}], "chars": ["<asker>:think:110", "<expert>:happy:110"]},
    {"bubbles": [{"lang": "en", "text": "……"}, {"lang": "zh", "text": "……"}], "chars": ["<english>:happy:110", "<asker>:happy:110"]}
  ],
  "diagram": "diagram.svg",
  "diagram_title": "告诉孩子跟着哪条剖面线、哪个流向或哪组趣味对比看",
  "takeaway": "用一句话直接输出同桌震撼金句（≤ 28 字）",
  "fact_title": "💡 同桌震撼",
  "fact": "紧扣主问题的爆表同桌震撼冷知识（≤ 45 字）",
  "host": "主持：asker × expert 的角色名",
  "sources": ["核实数字和冷知识的资料链接"]
}
```

`who`、`chars` 里写具体角色代号（任务单「角色槽位」查槽位由谁担），上面的 `<槽位>` 只是占位。

## 规则

- 4 格漫画节奏重塑（生活好奇抛出 → 极端荒谬机制 → 追问搞笑破绽 → 恍然大悟收尾）：版面按前两格 → 主图 → 后两格排列。english 槽位的角色用英文精炼复述关键点，不用无关笑话代替解释
  - **第 1 格（生活好奇抛出）**：asker 从日常生活、身体反应或极端环境抛出常人好奇或直觉反常的问题，承接封面悬念（如“宇航员在太空放屁，真的得憋回地球吗？”）；
  - **第 2 格（极端荒谬机制）**：引出看似荒谬却真实存在的硬核怪奇机制，结合主图（生动直观的剖面透视）把核心秘密亮出来；
  - **第 3 格（追问搞笑破绽）**：asker 追问更深一层的搞笑破绽或极端推论（“那要是没憋住……宇航服会像气球一样飞上天吗？”），追问必须被正面解答；
  - **第 4 格（恍然大悟收尾与社交货币）**：落到日常联想与同桌炫耀，english 槽位用英文复述关键点，`takeaway` 输出打赌/炫耀金句（≤ 28 字，直接反转直觉，成为孩子第二天在学校跟同学打赌的强力谈资）；
- **原理图（`diagram` SVG）绘制指南**：
  - **必须生动直观、剖面透视、趣味标注**：画成拟人剖面/流程透视（如人体剖面、宇航服气流循环、器官拟人化表情、动态气流箭头），一眼看懂核心机制；
  - **禁止枯燥抽象物理图**：杜绝物理受力坐标轴、受力分解图、教科书坐标系或枯燥抽象公式；
  - 格式规范：`viewBox="0 0 880 300"`，字体写 `font-family="ZCOOL KuaiLe, PingFang SC, sans-serif"`，中文标注 ≥ 24 号字（推荐 28 以上），可以为看清适度夸张比例；颜色用 `#4A3B32`（墨色）、`#FFE27A`（黄）、`#FF8A7A`（红）、`#7FD3BC`（绿）、`#8EC5FF`（蓝）；不引用外部网络图片；
  - 主图按实际剩余空间在 200–280px 间调整。关键路线、点或结构太小时加放大窗；连接线不能暗示错误的物理路径；
- **`fact` 强化社交货币价值（同桌震撼度）**：
  - `fact` ≤ 45 字，必须可查证、紧扣主问题，但必须具备极高的社交货币价值（“同桌震撼度”爆表，是孩子课间能脱口而出的第二记重锤谈资）；`fact_title` 可选（如 `💡 同桌震撼`、`💡 再发现`），≤ 8 字；
- **节日联动配合（轻量点睛）**：遇到特殊节日时，分格角色可佩戴轻量节日小道具（如南瓜帽），冷知识（`fact`）可轻量联动节日背景的真实科学（如南瓜生物学、夜行生物习性），点到即止，不喧宾夺主；
- 追问必须被直接回答，不能用另一个季节、地点或数字搪塞；历史/考古题讲清证据来源，区分事实与古人的信仰，不硬套物理机制；
- `panels[].title` 可选，≤ 12 字，写具体场景；`diagram_title` ≤ 28 字，指向图中具体观察点；`takeaway` ≤ 28 字，保持一行，不新增未经解释的结论。这些字段省略时旧稿仍可渲染；
- 每格单人对白硬上限 26 字，双人每句硬上限 20 字（中英文均按实际显示字符计数）；一格最多 2 个气泡。一格 1 个角色时尺寸 130，2 个时各 110，模板按 spec 显示，漫画格角色尺寸硬上限 130px（包括 `who` 中的 spec）；用 `who` 表明说话者。气泡只写纯文本，不使用 HTML 标签；数学符号 `<`、`>` 按字符计数并显示为文字，中文按词组换行；
- 字数通过不等于排版通过：渲染仍会检查页脚、正文重叠与文字越界；即使草稿模式也不会发布溢出的成品。

## 自检

`node scripts/pipeline.mjs check <issue>` 没有 `[comic]` 报错；数字自己算一遍或在 `sources` 里能查到；关键事实优先引用官方机构、博物馆或原始研究；SVG 能在浏览器打开、文字不出界；图中轨迹、光线、标签要互相一致，简化示意明确说明；按实际页面检查角色、气泡和图解没有裁剪或重叠。

# 今日一问 · 讲读

≤ 26 句（任务单 `narration_lines`），咕咕博士（expert）+ 团子狗（asker）+ 波波鼠（english）主持。

## 角色人设与互动节奏
- **咕咕博士（语速飙升讲冷知识）**：一讲到怪奇冷知识就兴奋得停不下来、像开了二倍速爆出硬核又怪奇的机制真相。
- **团子狗（用食物打断 / 呆萌发问）**：忍不住用食物（肉包子、香肠、烤红薯）打断博士的语速飙升，满脑子都是吃的，追问搞笑破绽与反常点（至少插嘴两次，追问往下走一层，不把上一个问题换个说法再问）。
- **波波鼠（精准吐槽 / 英文金句）**：在两人鸡同鸭讲时一针见血精准吐槽，并在高潮处用 1 句精炼英文（3–8 个词）做灵魂总结。

## 讲读骨架
1. **生活好奇开场**：团子狗先猜一个离谱或好笑的错误答案（常人直觉/食物脑脑洞）。
2. **怪奇机制展开**：咕咕博士语速飙升讲机制，用一个生动的身体或生活类比（气体乱窜、气球漏气、吹泡泡）。
3. **食物打断与追问破绽**：团子狗用食物打断并追问搞笑破绽（“那放屁会有烤红薯味吗？”）；咕咕博士正面解答破绽。
4. **硬核数字与对比**：一个可感知的惊人数字，讲慢一点、配生活比较（一口气吹灭蜡烛、几个气球容量）。
5. **精准吐槽与英文总结**：波波鼠精准吐槽并输出一句英文金句（3–8 词），咕咕博士自然接住并解释英文。
6. **社交行动点收尾**：最后引出同桌震撼或动手小实验（试着用吸管吹水杯感受气压、教孩子怎么说给同桌听），以“你也可以试试……”收尾（说了“试试”之后最多再有一句），说完翻页。

# 环球小报 · 讲读

≤ 24 句（任务单 `narration_lines`），三条新闻在 `thread` 里都点到。

- **全球特派员与情绪接梗**：
  - 波波鼠（english 槽位）担任“全球特派员”，带来世界各地的搞怪与奇趣情报，随口冒出地道英式感叹句（如 "No way!", "Seriously?", "Unbelievable!", "That's insane!" 等），现场感和惊叹情绪拉满；
  - 死党伙伴（团子狗、咕咕博士等）顺着情绪接梗、吐槽与捧哏（如“这也太神了吧！”“这乌鸦比我还会动脑筋！”），带上核心词自然呼应；
  - **不搞单词领读**：彻底摒弃教条生硬的“xxx 是 xxx 意思”式翻译领读，让英汉互动在纯粹的情绪碰撞与接梗中自然流淌。
- **头条 8–10 句**：先说照片里拍到了什么震撼奇趣的画面（`photo_shows`）→ 讲生动背景（`talk.background`）→ 一个尺度类比（`talk.scale`）→ 接到孩子自己身上（`talk.follow_up`）
- **两条短讯各 4–5 句**：各有一个角色的趣味反应、只讲一个数字
- 每条新闻由波波鼠随口带入地道英文短句或感叹，死党伙伴顺着情绪接梗
- 最后念"你怎么看"（`ask_zh`），停 3 秒让孩子想

# 环球小报（news）

定位：**奇趣吉尼斯 / 动物大显神通 / 极客脑洞发明（拓宽眼界的新鲜感）**。波波鼠担任“全球特派员”，发回世界各地的搞怪与奇趣情报。

2 条（大图版：1 条大头条超大图 + 1 条精选次条大图，推荐）或 3 条（经典版：1 条头条 + 2 条并排短讯）最近 7 天适合孩子的真实奇趣新闻。大图版图大字少、视觉冲击强、信息不拥挤；页面保持简短，讲读版靠 `talk` 讲得更丰富。

案例示范（大图版 2 条）：
- 大头条（超大图）：日本一只乌鸦学会了自己用石子投进自动饮水机喝水；
- 精选次条（大图）：瑞士用无人机给雪山上的牛送草料。

## 开工

1. 领任务单：`node scripts/pipeline.mjs ticket <issue> news`，照单上的规则、参数、角色槽位写；最后一行的指纹写进 `_meta.ticket`
2. 读任务书、`data/profile.md`（兴趣）
3. 写 `issue/news.json`，字段见同目录 `schema.json`

```json
{
  "_meta": {"stage": "news", "by": "", "at": "", "ticket": "<任务单指纹>"},
  "week": "10.06–10.12",
  "items": [
    {"flag": "🇯🇵", "place": "日本 · 横滨", "title": "乌鸦自制“投石取水器”喝水！", "text": "横滨公园里一只乌鸦学会把小石子叼进感应饮水机，水流出来后开心畅饮！",
     "word": {"en": "clever", "zh": "聪明的"},
     "photo_url": "原图直链", "photo_credit": "摄影师 / 来源", "photo_pos": "center 30%",
     "photo_shows": "一只黑乌鸦嘴里叼着石子悬停在饮水机按钮上方",
     "talk": {"background": "研究人员在公园观察了两个月，发现这只乌鸦每天口渴时都会找来特定大小的鹅卵石按压开关……", "scale": "它的工具使用水平相当于七岁小朋友的智力", "follow_up": "你家身边的鸟类也有什么让你吃惊的聪明举动吗？"},
     "sources": ["报道链接", "另一个独立来源"]}
  ],
  "ask_zh": "你怎么看？……", "ask_en": "……?",
  "credits": "来源：…… 照片：……",
  "foot": ""
}
```

## 规则

- **选题标准强制限定（拓宽眼界的新鲜感）**：
  1. **动物超常行为**：动物展示超强智力、使用复杂工具、超凡社交互助或搞笑反常习惯；
  2. **吉尼斯搞怪纪录**：大开脑洞、不可思议的奇趣挑战与世界纪录；
  3. **小学生或极客民间发明**：日常生活里的脑洞改造、极客小发明、动手解决具体小问题的神器。
- **红线严禁**：严禁宏大叙事、宏观经济、枯燥国际时政、外交首脑、战争政治或严肃会议公报。只选能让孩子脱口而出“哇塞！”“这也行？”的新奇鲜活事实。
- 来源：News for Kids、Science News Explores、DOGOnews、Time for Kids、BBC Newsround、Guinness World Records、UPI Odd News 等儿童或奇闻科普媒体
- 每条至少再找 1 个独立来源核实，两个链接都写进 `sources`
- 只选正向、好奇心向的新闻；政治、选举、抗议、灾难、暴力类一律跳过；不出现真实 IP 角色
- 这个栏目用新闻原图（`image_policy: private-ok`），只能放在私有数据目录里，`photo_credit` 写清来源；全刊是 `free-only` 的杂志用不了这个栏目。找不到原图时用自由授权的同类照片，并在 `foot` 写"照片为示意"
- **配图必须视觉冲击力强、一眼即明**：照片必须抓人眼球，直接拍到新闻里那个最不可思议、最奇趣的真实画面（那只正在投石的乌鸦、雪山上空吊着草料的无人机、延绵壮观的乐高多米诺长龙），孩子不读文字也能一眼看懂奇趣或震撼所在。
  - 严禁会议合影、抽象图标、图表或概念示意图；
  - 没有强视觉冲击的真实好照片，立刻换选题；
  - `photo_shows` 用一句话写照片里实际拍到了什么。
- 选新闻时把"有没有好照片"当作首要条件之一；第 1 条是头条，照片视觉冲击力要最强
- 优先孩子的兴趣（看 `profile.md` 的兴趣权重）：动物、搞怪发明、动手制作、极限挑战
- `talk` 给讲读版用，页面上不显示：`background` 2–3 句背景（谁、怎么发现的、过程里最有意思的细节）；`scale` 一个把数字变成孩子摸得着的类比（"相当于 3 辆校车那么长"）；`follow_up` 一个顺着往下想的追问。事实都要出自 `sources`
- `text` ≤ 50 字；`word` 按任务单的英文档位挑；`ask_zh` 是一道需要说理由的"你怎么看"
- `foot` 一般留空，模板会自动写"新闻来源已交叉核实 · 往后翻：下一页"；道别放在最后一页信箱

## 图片

照片放 `assets/news/`（大图版 2 张，经典版 3 张）：

```sh
node sections/news/fetch.mjs <issue>                    # 用每条的 photo_url
node sections/news/fetch.mjs <issue> <直链 1> <直链 2>   # 或在命令行给直链
```

脚本打印出 `assets.json` 要写的 `news`（路径带 `news/`），照抄进去。

## 自检

`node scripts/pipeline.mjs check <issue>` 没有 `[news]` 报错；每条两个来源说法一致；只看照片能认出是什么且具视觉冲击力；选题符合动物超常行为/搞怪纪录/民间发明三类之一；`talk` 的事实来源里查得到；日期在最近 7 天内（以报道日期为准，事件较早时在 `text` 里交代）。

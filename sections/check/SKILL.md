# 真的假的（check）

每天一页，排在环球小报后面。

**栏目定位**：朋友圈谣言粉碎机 / 生活怪谈。给孩子“戳穿大人谎言与生活怪谈”的成就感与探索快感，彻底去除“思维工具/本领训练”的说教上课感。
拿一条孩子真会在长辈朋友圈、家族群、同学闲聊、短视频里听到的离奇说法或生活怪谈（例如大人的善意吓唬、民间迷信、养生偏方或童年都市传说），先让快脑袋凭直觉选「真的 / 假的 / 说不清」，再通过 3 条生活化、角色化的破谣线索（咕咕博士科学求证、团子狗以自身经历现身说法、生活常识对照），让慢脑袋层层剥开真相，最后写下自己的粉碎结论。最终答案倒印在页脚，让孩子在倒转杂志的瞬间享受破解谣言的成就感。

数据目录有 `thinking-plan.md` 时，若调度传入了 `skill`、`choices`、`tools` 参数，将其转化为“谣言粉碎行动”的探案侦探切入点（如“这句传言是事实还是别人吹牛的观点？”），选项和查证工具跟着换，但正文与线索绝不出现说教字眼。

## 开工

1. 领任务单：`node scripts/pipeline.mjs ticket <issue> check`，照单上的规则、参数、角色槽位写，最后一行的指纹写进 `_meta.ticket`
2. 读 `issue/brief.json`（日期）、`data/thinking-plan.md`（可选）、`data/profile.md`（兴趣）、最近几期的 `issue/check.json`（避免重复）、任务单的 `skill`/`choices`/`tools` 参数
3. 写 `issue/check.json`，字段见同目录 `schema.json`

```json
{
  "_meta": {"stage": "check", "by": "", "at": "", "ticket": "<任务单指纹>"},
  "where": "长辈朋友圈 · 养生大揭秘",
  "claim": "吃西瓜不吐籽，西瓜会在肚子里发芽长出西瓜！",
  "likes": "18万", "comments": "3,420",
  "photo_url": "", "photo_credit": "", "photo_pos": "center",
  "clues": [
    "团子狗现身说法：昨天吞了一大把西瓜籽，除了肚皮滚圆啥也没长出来。",
    "咕咕博士实验报告：胃酸是强酸性（pH 1–2），种子根本无法存活。",
    "植物学常识：植物萌发需要土壤、空气和阳光，黑漆漆的胃里全没有。"

  "truth": "false",
  "verdict": "假的！胃液强酸且缺阳光土壤，西瓜籽根本无法发芽。",

  "sources": ["中国植物学会科普数据库", "国家消化系统疾病临床医学研究中心"]

```

```json

  "verdict": "观点！「可爱」每个人感觉不一样，量不出来。"

```

## 规则

- **谣言粉碎行动定位**：彻底去除“思维工具/本领训练”的说教用语，改为“谣言粉碎行动”。说法、线索、`verdict` 和讲读稿一律不得出现"思维本领""思维方法""思维工具""本领训练""今天学""今天练"等说教上课感字眼，就是一场好玩的破谣侦探行动（声明 `no-visible-pedagogy` 规则）。
- **3 条证据线索角色化、生活化**：
  - 正好 3 条，各 ≤ 36 字。
  - 角色化与生活化分工明确：
    1. 真实生活体验 / 角色现身说法（如团子狗自身吃撑、亲历吐槽或生活观察）。
    2. 科学求证 / 实验数据（如咕咕博士的显微镜、化学反应、强酸 pH 1–2、对照实验等客观数据）。
    3. 科学原理 / 常识对照（如植物发芽三要素、身体机制等常理推导）。
  - 3 条线索层层推进、合力推导答案，但不直接剧透最终判定。
- **答案倒印在页脚**：
  - `verdict` ≤ 40 字，开头写"假的！"“真的！”或“一半对！”（有 `choices` 时写选中的那一项，如"观点！"），再给一句有力的科学破谣理由。
  - 页面倒印在页脚，让孩子自己动手把杂志倒过来看答案，享受戳穿谎言的成就感。
- **题材偏向生活怪谈与长辈朋友圈流传说法**：
  - 选孩子真会在生活场景中听到的“怪谈”或大人叮嘱，例如“吃西瓜不吐籽肚里发芽”“指月亮会被割耳朵”“吃耳屎变哑巴”“吞口香糖黏住肠子”“金鱼记忆只有7秒”“仙人掌能防电脑辐射”等。
  - 说法要有真有假：大约三分之一是真的（反直觉但真实的科学生活事实，如“章鱼有三颗心脏”“香蕉其实是草本植物结的果”），`truth` 可以是 `true`、`false`、`half`（一半对）。别让孩子摸出“一律选假”的规律。
- `claim` ≤ 30 字，写成网上流传或长辈叮嘱的原样口气；`where` 写一个泛称的出处（"长辈朋友圈""家族群""同学闲聊""某短视频"），不写真实账号名；`likes`、`comments` 随手编个像样的互动数。
- 题材优先贴近孩子生活体验与身体常识（身体、食物、植物、动物、日常物理）；尽量和当天其他页错开。
- 配图可选：有一张一眼看懂、和说法直接相关的自由授权照片就放（`photo_url`、`photo_credit`），没有就留空。
- 按内容红线过滤：不碰健康偏方、谣言恐慌、政治、灾难、对具体人群的评价；不点名真实博主或媒体。
- `sources` 至少 2 个独立可靠来源（科研机构、博物馆、儿童科学媒体）。

## 自检

`node scripts/pipeline.mjs check <issue>` 没有 `[check]` 报错；真假结论两个来源说法一致；3 条线索角色化生活化且不剧透；最近一周的答案不是同一个选项（真、假、一半对，或者事实、观点、都有，都出现过）；有课表时 `skill` 和任务单参数一致。

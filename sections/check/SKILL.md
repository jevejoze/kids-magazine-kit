# 真的假的（check）

每天一页，排在环球小报后面。拿一条孩子真会在网上、短视频里、同学嘴里碰到的说法，先让快脑袋凭感觉选「真 / 假」，再给 3 条线索让慢脑袋查一查，最后写下自己的结论。答案倒印在页面底部。练的是查证的习惯：谁说的、有证据吗、别处怎么说。数据目录有 `thinking-plan.md`（思维课表）时，每周练一样思维本领（找证据、区分事实和观点、理由合理吗、以偏概全……），这一页照本周的本领出题，选项和查证工具跟着换——这些由调度算进任务单的 `skill`、`choices`、`tools` 参数。

## 开工

1. 领任务单：`node scripts/pipeline.mjs ticket <issue> check`，照单上的规则、参数、角色槽位写，最后一行的指纹写进 `_meta.ticket`
2. 读 `issue/00-brief.json`（日期）、`data/thinking-plan.md`（可选，本周练什么）、`data/profile.md`（兴趣）、最近几期的 `issue/19-check.json`（避免重复）、任务单的 `skill`/`choices`/`tools` 参数（本周课表）
3. 写 `issue/19-check.json`，字段见同目录 `schema.json`

```json
{
  "_meta": {"stage": "19-check", "by": "", "at": "", "ticket": "<任务单指纹>"},
  "where": "某短视频 · 科普小达人",
  "claim": "金鱼的记忆只有 7 秒，所以它永远不会无聊。",
  "likes": "23万", "comments": "4,512",
  "photo_url": "", "photo_credit": "", "photo_pos": "center",
  "clues": [
    "有人训练金鱼推小杠杆换食物，隔了几天它还会推。",
    "鱼缸里的金鱼会在喂食时间游到同一个角落等。",
    "这个说法从哪来？找不到最早做这个实验的科学家。"
  ],
  "truth": "false",
  "verdict": "假的！金鱼能记住好几个月，会认喂食时间和地点。",
  "explain": "给讲读稿和信箱用的两三句解释，事实出自 sources",
  "sources": ["可靠来源", "另一个独立来源"]
}
```

有思维课表、本周的本领不是"真还是假"时，加这几个字段，`truth` 换成 `answer`：

```json
{
  "skill": "事实还是观点",
  "claim": "企鹅是世界上最可爱的鸟，谁不同意谁就没眼光。",
  "choices": ["📏 事实", "💭 观点", "🧩 都有"],
  "answer": "💭 观点",
  "tools": [["📏 能量出来吗？", "称一称、数一数、查一查"], ["💭 换个人会变吗？", "有人觉得别的鸟更可爱"], ["🔍 哪个词露馅了？", "最、谁不同意……"]],
  "verdict": "观点！「可爱」每个人感觉不一样，量不出来。"
}
```

## 规则

- **按课表出题**：任务单带了 `skill`/`choices`/`tools` 参数时，照参数的写法出：`skill` 照抄本周本领（≤ 10 字），说法、选项（`choices` 2–3 个，各 ≤ 8 字含表情）、查证工具（`tools` 3 个 `[标题, 小字]`）按参数给的写法出；`answer` 是 `choices` 里的一个。本周本领就是查真假，或者没有课表时，照默认写法、不写这几个字段——本期渲染会用默认的「真的/假的/说不清」三选项
- **不点明在练什么**：`skill` 只留在 `_answers` 里给家长看；说法、线索、`verdict` 和讲读稿都不出现"练""本领""今天学""思维方法"这类字眼，就是一道好玩的题（声明 `no-visible-pedagogy` 规则）
- 同一周里每天换一个题材，难度从周一到周四一点点往上加；周日的题可以把本周的本领再用一遍，换一个孩子没见过的场景
- `claim` ≤ 30 字，写成网上流传的原样口气；`where` 写一个泛称的出处（"某短视频""同学说""某公众号"），不写真实账号名；`likes`、`comments` 随手编个像样的数
- 说法要有真有假（查真假的那几周）：大约三分之一是真的（反直觉但真的，如"章鱼有三颗心"），`truth` 可以是 `true`、`false`、`half`（一半对）。别让孩子摸出"一律选假"的规律
- 题材优先孩子的兴趣和本周学过的东西（动物、海洋、身体、太空）；尽量和当天其他页错开
- `clues` 正好 3 条，各 ≤ 36 字：一条讲来源（谁说的、怎么知道的），一条讲证据（实验、观察、数字），一条讲别处怎么说或常识对照；线索要能推出答案，又不直接说出答案
- `verdict` ≤ 40 字，开头写"真的！""假的！"或"一半对！"（有 `choices` 时写选中的那一项，如"观点！"），再给一句理由；页面倒着印
- 配图可选：有一张一眼看懂、和说法直接相关的自由授权照片就放（`photo_url`、`photo_credit`），没有就留空
- 按内容红线过滤：不碰健康偏方、谣言恐慌、政治、灾难、对具体人群的评价；不点名真实的博主或媒体
- `sources` 至少 2 个独立可靠来源（科研机构、博物馆、儿童科学媒体）

## 自检

`node scripts/pipeline.mjs check <issue>` 没有 `[19]` 报错；真假结论两个来源说法一致；3 条线索不剧透；最近一周的答案不是同一个选项（真、假、一半对，或者事实、观点、都有，都出现过）；有课表时 `skill` 和任务单参数一致

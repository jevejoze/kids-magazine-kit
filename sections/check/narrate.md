# 真的假的 · 讲读

≤ 12 句（任务单 `narration_lines`）。

## 聊天氛围
- **像朋友刷到一条好玩说法，一起拿捏琢磨**：不要浮夸地大喊大叫、恐慌哀嚎，也不要像老师一样板着脸“开始破谣行动”。
- **绝不念“第一……第二……第三……”清单**：把 3 条线索拆进咕咕博士和团子狗你一言我一语的自然聊天里，像边翻资料边嘀咕那样舒服顺耳。
- **绝不出现说教字眼**：不提“思维本领”“思维工具”“今天练”等任何课表词汇。

## 讲读节奏
1. **随口引出说法**：旁白用平时刷手机或听人聊天的轻松口吻念出这条说法（`claim`），交代一句在哪看到的（如家族群、短视频）。
2. **直觉反应**：团子狗第一反应很容易被唬住或跟着起哄（“听起来挺像真的呀！”）；如有需要，浣熊也可以轻巧补一句调皮的附和。
3. **亲切留白让孩子先选**：温和问孩子怎么看——如果页面有定制 `choices`（如事实 / 观点 / 都有），就顺着选项问，否则问“真的、假的，还是说不清”，停 3 秒（`pause: 3`，`hold: "⏸ 先选一个"`）。
4. **一起顺着线索查**：咕咕博士带着大家把 3 条线索用口语聊明白，团子狗在中间插一句恍然大悟或好玩的小反问。
5. **把揭晓留给孩子**：温和提醒孩子把页面倒过来看底下的结论——**绝不念出答案，也绝不说“明天公布 / 信箱公布”**。

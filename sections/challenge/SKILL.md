# 挑战（challenge）· 方案 A 强联动：案发现场与物证破译

每天一页，排在小剧场后面。**彻底废除纯文字奥数逻辑题与复杂算术应用题（做题压力大、文本枯燥）**，全面转向**视觉解谜（草图寻宝、密码盘/摩斯码破译、反转镜像字、视觉找茬）**，承接 P2 小剧场的案发现场与物证线索，给小读者提供即时反馈与动手动脑的破译快感。

## 开工

1. 领任务单：`node scripts/pipeline.mjs ticket <issue> challenge`，照单上的规则、参数、角色槽位写，最后一样的指纹写进 `_meta.ticket`
2. 读 `issue/brief.json` 和 `issue/story.json`（承接上一页现场物证）
3. 写 `issue/challenge.json`，字段见同目录 `schema.json`

## 视觉解谜规则

- **承接 P2 案发现场（强联动方案 A）**：
  - 承接 P2 小剧场抓现行后嫌疑人（如捣蛋浣熊）设下的谜局或遗留现场草图；
  - 谜题围绕具体物品（标本藏匿处、神秘钥匙、密码箱、现场丢失物）展开，读者从看客转变为“破译行动者”。
- **全面转向四大视觉解谜题型**：
  1. **草图寻宝 / 现场地图（sketch）**：捣蛋鬼手绘的阁楼草图、宝箱阵列、房间俯视图，通过直观视觉方位与排除法圈出目标（如第几个抽屉、哪块地板）；
  2. **密码破译 / 密码盘 / 摩斯电码（cipher）**：给出图形符号对照表、摩斯密码符（`· -`）或密码盘，对照解开 2~3 组密码线索；
  3. **反转镜像字（mirror）**：捣蛋鬼在玻璃、反面纸条留下的反向字，利用镜像翻转思维直接识别文字信息；
  4. **现场找茬 / 物证对比（spot_diff）**：对比两处案发现场细节或物品微破绽，找出被调包或遗漏的物品。
- **即时反馈与动手快感**：
  - 规则一眼看懂，去除做题压力，鼓励在平板上直接比对、指认与观察；
  - 答案必须在**本页右下角倒印**（旋转 180°），想好之后转动平板即可核对，获得即时破译的正向反馈。
- **文字与版面预算**：
  - `taunt_zh` ≤ 20 字，捣蛋鬼嘴硬下注挑衅，和解谜紧密相关；
  - `body` ≤ 120 字，精简交代情境与规则；
  - `clues` 每条一条线索，可结合 `[摩斯]`、`[镜像]`、`[草图]` 标识；
  - `question` 明确发问求解目标；
  - 情境、条件和问题合计 ≤ 240 字，把充分版面留给视觉卡片与图示；
  - `answer` 是简明明确的最终答案（倒印在右下角）；`solution` 包含完整推导过程供审核。

## 自检

`node scripts/pipeline.mjs check <issue>` 没有 `[challenge]` 报错；视觉解谜有唯一解；规则直观，富有即时反馈与动手快感。

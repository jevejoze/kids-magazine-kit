# 小剧场 · 讲读

≤ 30 句（任务单 `narration_lines`），旁白 + 四位小伙伴一起演。

## 讲读规则

- **像轻松好听的探案广播剧**：
  - 伙伴们在阁楼里各抒己见、有来有往（浣熊偶尔嘴硬、团子狗委屈又憨厚、波波鼠冒出一两句地道英文感叹、咕咕博士温和冷静地找线索），冲突好玩不伤和气；
  - 灵活运用有效情绪标签（`委屈`、`得意`、`神秘`、`紧张`、`惊讶`、`开心`、`温柔`），让画面活起来。
- **用停顿和细节留出线索**：
  - 关键物证或破绽露出来时，不急着由旁白直接点破，可以留出角色反应或 2–3 秒短暂停顿（`pause: 2`–`3`），让孩子用耳朵先一步察觉端倪；
  - 如果 `data/sfx/` 里有匹配音效（如 `footsteps`、`door`、`drum`、`slurp`），可在关键动作前点缀，没有也能靠台词自然推进（至少包含一处 `sfx` 或 `pause ≥ 2`）。
- **先动作后台词，先交代后发问**：
  - 原文“某某做了什么：「台词」”拆成旁白一句画面动作 + 角色一句台词，两句都留，确保闭眼听也能跟上；
  - 角色不抢着问旁白还没交代的东西。
- **侦探笔记留白与结尾悬念**：
  - 紧张处放慢语速 → 旁白念侦探笔记（照 `story.json` 的 `clue` 念），留 3–5 秒思考时间（`pause: 3`–`5`，`hold: "🔍 找找线索吧"`）；
  - 结尾转成 `神秘` 或 `温柔` 语气，如果本期有联动的挑战页可顺势引出下一页草图，否则留一个牵动人心的温和悬念。
- **信箱不重复**：信箱里的明天预告不重复本页的 `tbc`。

# 小剧场（story）· 方案 A 强联动：案发现场与物证破译

编辑部推理连载的一集：一页中文生活悬念小故事。废除空洞的 200 字密室排除流水账（门窗未动），转向**生活悬念 / 具象视觉抓现行（抓角色小破绽的智力优越感）**，并在结尾将物证与解谜草图无缝联动承接到 P3 挑战页。

## 开工

1. 领任务单：`node scripts/pipeline.mjs ticket <issue> story`，照单上的规则、参数、角色槽位写；最后一样的指纹写进 `_meta.ticket`
2. 读任务书的 `story` 块（`ep`、`resolve`、`plan`）和任务单「要读、要更新的状态」里的文件：
   - `state/story/config.md`：家长写的设定（场景、人物关系、口吻）
   - `state/story/log.jsonl`：前几集，一集一行
   - `state/story/open-threads.md`：还没回收的伏笔
3. 写 `issue/story.json`，字段见同目录 `schema.json`

```json
{
  "_meta": {"stage": "story", "by": "", "at": "", "ticket": "<任务单指纹>"},
  "ep": 5, "night": false,
  "title_zh": "……", "title_en": "……",
  "paragraphs": ["……", "……"],
  "scene": ["<asker>:sleepy:150", "<expert>:think:150:magnifier", "<english>:surprise:150", "<trickster>:smirk:150"],
  "clue": "侦探笔记：……？",
  "tbc": "……快翻到下一页破解草图！To be continued…",
  "secret": "本集真相、微破绽物证、嫌疑人辩解、干扰线索（只给家长看）",
  "summary": "一句话本集摘要，归档写进 log.jsonl",
  "threads_after": ["本集之后还没回收的伏笔，每条一句"]
}
```

`scene` 里写具体角色代号（任务单「角色槽位」查槽位由谁担），上面的 `<槽位>` 只是占位。

## 微破绽侦探生活案规则

- **定位升级（抓小破绽的智力优越感）**：拒绝干瘪的“门窗紧锁密室排除”流水账。故事从日常生活悬念切入（零食被偷吃、神秘夜半声响、珍稀标本失踪、道具被恶搞换掉），核心乐趣在于**通过具象物理/视觉破绽当场戳穿嫌疑人的嘴硬辩解**。
- **必须包含视觉化痕迹证据**：
  案件中必须出现明确的肉眼可见物理痕迹，供小读者一眼或对照识别：
  1. **食物残渣**：爪子或嘴角粘着的薯片碎屑、巧克力酱、果冻渍、黑糖珍珠等；
  2. **化学/物理变色与光效**：紫外灯照射下的荧光粉反应、指甲油颜色对比、遇水变色、受热褪色；
  3. **道具与随身物品遗落**：特有纽扣、工具刷毛、包装纸袋撕角、特定脚印与指纹爪印。
- **嫌疑人现场对质与嘴硬机制**：
  - 设置 2~3 位嫌疑角色，各人在现场有不同状态（例如：团子狗抓满薯片碎在偷吃零食、波波鼠刚涂红指甲油没干在美甲、捣蛋浣熊两手干干净净直喊冤说没碰过）；
  - 嫌疑人嘴硬声称“绝对没碰过”，但身上的视觉化痕迹证据（如紫外灯下泛起微弱荧光）当场打脸抓现行。
- **案例示范（古代荧光甲虫失踪案）**：
  - *案情*：咕咕博士珍藏的古代荧光甲虫标本在标本盒里失踪了，该甲虫表面涂有特制保护荧光粉。
  - *嫌疑人检查*：三位嫌疑人伸手自证——团子狗爪子上全是薯片渣，波波鼠爪子涂了湿漉漉指甲油，捣蛋浣熊两手看似干干净净，嘴硬说碰都没碰。
  - *破绽与现行*：咕咕博士拿出紫外灯照射，浣熊的爪子上泛着微弱绿荧光，铁证如山，当场被抓现行！
- **与 P3 挑战页强联动（方案 A）**：
  - 故事结尾抓到嫌疑人小破绽后，引出被藏匿物品的物证线索（例如：浣熊承认拿了标本，但藏进了阁楼机关，并留下一张涂鸦草图或反转暗号纸条）；
  - `tbc` 或结尾段落直接提示读者翻到下一页 P3 挑战页，由小读者亲自动手破译草图与密码，找回真宝物。
- **正文字数与排版规范**：
  - 每集都用中文写，≤ 300 字。段落 ≤ 4 段，提到 english、asker、expert、trickster 角色名字的段落分别排成对应的角色对白行；
  - 关键物证与破绽可用 `<em>……</em>` 醒目标记；
  - `clue`（侦探笔记）针对现场视觉破绽或最新物证发问（如“哪位嫌疑人的手在紫外灯下露出了破绽？”），启发孩子观察推理并引向 P3。

## 状态

- `threads_after` 是本集之后的完整伏笔清单：旧伏笔这集回收了就去掉，新埋的加上；都回收了写 `[]`
- 本步只写 `story.json`。archive 这一步归档时才把本集追加进 `log.jsonl`、用 `threads_after` 重写 `open-threads.md`，所以一期定稿后状态才变
- 数据目录还没有 `state/story/`（旧档案 `story-bible.md`）时照旧写 `bible_update`，归档追加进 `story-bible.md`

## 自检

`node scripts/pipeline.mjs check <issue>` 没有 `[story]` 报错；字数 ≤ 300；必须有视觉化痕迹证据；只看正文和现场破绽能推翻嫌疑人的谎言并得出 `secret` 里的真相。

# 秘密信箱（mailbox）

杂志的最后一页，定位为**读者秘密树洞 + 脑洞吐槽**。彻底抛弃原先模板化的“5 个机械问卷”（最喜欢哪一页/哪一页不太喜欢/难不难，像做作业评价表），为孩子营造被同龄死党真正理解、倾听与陪伴的私密树洞感。

包含两大核心板块：
1. **编辑部翻车公开处刑台**：公开本周/本期编辑部成员的丢人搞砸大事件（如捣蛋浣熊的发明让阁楼大停电跳闸、咕咕博士把袜子当成茶叶煮进了咖啡、波波鼠喝珍珠奶茶卡住了吸管、团子狗梦游把作业当零食啃）。通过角色带头自曝糗事、死党互相无情吐槽，彻底打破高高在上的权威感和说教感，让孩子感到无比亲切、好玩。
2. **秘密树洞（向死党倾诉 / 挑战蠢问题）**：向同龄死党倾诉心里的小秘密/烦恼，或向博学的博士（或其他编辑部成员）发起反套路提问（例如：“向博士提一个他绝对答不上来的蠢问题”）。提供趣味反套路脑洞示范（如“长颈鹿打嗝需要多长时间？”、“为什么蚊子不喝可乐？”），并在手账涂鸦区留白，极度降低孩子的思考与互动门槛，让孩子跃跃欲试。

页脚“说给谁听”来自 `magazine.yaml` 的 `send_note`（经 `brief.json` 带下来），不在这一步重写。

## 开工

1. 领任务单：`node scripts/pipeline.mjs ticket <issue> mailbox`，照单上的规则、参数、角色槽位写，最后一行的指纹写进 `_meta.ticket`。
2. 读 `issue/brief.json`（`last_feedback`）、`data/letters.md`、周六读上一期的 `issue/think.json`。
3. 写 `issue/mailbox.json`，字段见同目录 `schema.json`（注：示例中“小满”为占位名，生成时必须替换为当期读者实际称呼，见 brief.json 或 magazine.yaml 的 `call`）。

```json
{
  "_meta": {"stage": "mailbox", "by": "", "at": "", "ticket": "<任务单指纹>"},
  "hello": "<读者称呼>早上好！欢迎来到本期秘密阁楼，死党们又有翻车大事件了！",
  "blunder": {
    "who": "raccoon",
    "title": "土豆发电大断电",
    "desc": "捣蛋浣熊说要用发芽土豆给阁楼供电，火花一闪全楼跳闸，咕咕博士的咖啡直接煮成了胡椒袜子味！"
  },
  "treehole": {
    "target": "owl",
    "question": "向博士提一个他绝对答不上来的蠢问题！",
    "hint": "比如：长颈鹿打嗝需要多长时间？把你的反套路脑洞画在便签上！"
  }
}
```

## 规则

- **彻底删除 5 个机械问卷**：严禁出现“最喜欢哪一页”、“哪一页不太喜欢”、“今天难不难”等作业评价表式提问。
- **不写 `answers`**：不公布上期封面或谜题答案；本期谜题答案已在挑战页底部倒印。
- **`hello` ≤ 60 字**：死党式热情开场，叫孩子的实际称呼（按任务书或 magazine.yaml 的 `call`，切勿照抄占位名）。收到上期打卡/反馈就接住孩子的一句话（原话、提问或脑洞）；没收到就由一个角色爆料一句死党私密趣事。
- **`blunder`（翻车榜）规范**：
  - `who`：责任角色 ID（如 `raccoon`、`owl`、`dog`、`mouse` 或槽位）。
  - `title` ≤ 16 字：简短、戏谑的翻车案件名称。
  - `desc` ≤ 100 字：生动的搞砸经过，充满画面感与死党间搞怪互动。
- **`treehole`（秘密树洞）规范**：
  - `target`：提问或倾诉的对象角色 ID（如 `owl`）。
  - `question` ≤ 30 字：反套路提问挑战或死党倾诉主题。
  - `hint` ≤ 60 字：极低门槛的脑洞示范（如天马行空的反套路蠢问题示范）。
- **周六联动**：接住周五的周末思辨，`hello` 或 `treehole` 问一句聊得怎么样（如“昨天的话题，家里谁说服了谁？”）；周五的信箱不重复思辨话题。
- **真实陪伴，杜绝编造**：不编造孩子没说过的原话；不写长篇大论的说教信，不放集章、积分或作业奖励。
- **不写 `send_note`**：页脚“说给谁听”由 `magazine.yaml` 统一配置，这一步不用写。

## 自检

`node scripts/pipeline.mjs check <issue>` 没有 `[mailbox]` 报错；字数合规；`blunder` 与 `treehole` 结构完整；没有上期答案；严禁包含 5 个机械问卷。

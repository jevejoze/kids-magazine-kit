# 秘密信箱（mailbox）

杂志的最后一页。不放问卷（“最喜欢哪一页”“难不难”这类像作业评价表的提问），只做两件事：让孩子看到编辑部也会搞砸、搞砸了也没关系；给她留一个随手就能回的口子。

页面上有三块：

1. **悄悄话**（`hello`）：一句问候。
2. **今日翻车**（`blunder`）：本期一位编辑部成员搞砸了一件小事（捣蛋浣熊的发明让阁楼跳闸、咕咕博士把袜子当茶叶煮进了咖啡）。最后由另一位死党说一句（`makeup`），落在和好上。
3. **树洞**（`treehole`）：请孩子问一个能难倒某位成员的怪问题，给一个示范，下面留一块空白，写一句、画一笔都行。整页要动手的只有这一处。

页脚“说给谁听”来自 `magazine.yaml` 的 `send_note`（经 `brief.json` 带下来），不在这一步重写。

## 开工

1. 领任务单：`node scripts/pipeline.mjs ticket <issue> mailbox`，照单上的规则、参数、角色槽位写，最后一行的指纹写进 `_meta.ticket`。
2. 读 `issue/brief.json`（`last_feedback`）、`data/letters.md`、周六读上一期的 `issue/think.json`。
3. 写 `issue/mailbox.json`，字段见同目录 `schema.json`（注：示例中“小满”为占位名，生成时必须替换为当期读者实际称呼，见 brief.json 或 magazine.yaml 的 `call`）。

```json
{
  "_meta": {"stage": "mailbox", "by": "", "at": "", "ticket": "<任务单指纹>"},
  "hello": "<读者称呼>早上好！阁楼今天有点焦味，往下看就知道为什么。",
  "blunder": {
    "who": "raccoon",
    "title": "土豆发电大断电",
    "desc": "捣蛋浣熊说要用发芽土豆给阁楼供电，火花一闪全楼跳闸，咕咕博士的咖啡直接煮成了胡椒袜子味！",
    "makeup": "咕咕博士：下回先画电路图，我陪你。"
  },
  "treehole": {
    "target": "owl",
    "question": "问一个博士答不上来的怪问题！",
    "hint": "长颈鹿打嗝需要多长时间？"
  }
}
```

## 规则

- **不放问卷**：不出现“最喜欢哪一页”“哪一页不太喜欢”“今天难不难”等作业评价表式提问。
- **不写 `answers`**：不公布上期封面或谜题答案；本期谜题答案已在挑战页底部倒印。
- **`hello` ≤ 60 字**：叫孩子的实际称呼（按任务书或 magazine.yaml 的 `call`，切勿照抄占位名）。收到上期反馈就接住孩子的一句话（原话、提问或脑洞）；没收到就由一个角色说一句编辑部里的小事。
- **`blunder`（今日翻车）**：
  - `who`：翻车的角色 ID（如 `raccoon`、`owl`、`dog`、`mouse` 或槽位）。
  - `title` ≤ 16 字：这件事的名字，页面上直接印，不加“案件”之类的前缀。
  - `desc` ≤ 100 字：搞砸的经过，有画面。
  - `makeup` ≤ 20 字（含说话人）：另一位死党说的一句，写成「团子狗：眼镜在你头上！下次一起躺着看。」。每期重新写，落在和好或一起想办法上，不重复上一期。
  - **不写成当众出丑**：不用“处刑”“丢人”“判定”“绝不原谅”这类词，不打分、不评星。搞砸的事是好笑的，不是丢脸的（内容红线：冲突最后和好）。
- **`treehole`（树洞）**：
  - `target`：被提问的角色 ID（如 `owl`）。
  - `question` ≤ 30 字：请孩子问一个怪问题或说一句心里话。写“怪问题”，不写“蠢问题”。
  - `hint` ≤ 60 字：一两个示范问题，直接写问题本身；页面自动加「比如：」，这里不用写，也不用再写“画在便签上”。
- **周六联动**：接住周五的周末思辨，`hello` 或 `treehole` 问一句聊得怎么样（如“昨天的话题，家里谁说服了谁？”）；周五的信箱不重复思辨话题。
- **不编造**：不编造孩子没说过的原话；不写长篇说教信，不放集章、积分或作业奖励。
- **不写 `send_note`**：页脚“说给谁听”由 `magazine.yaml` 统一配置，这一步不用写。

## 自检

`node scripts/pipeline.mjs check <issue>` 没有 `[mailbox]` 报错；字数合规；`blunder`（含 `makeup`）与 `treehole` 结构完整；`makeup` 落在和好上、和上一期不一样；没有上期答案；没有问卷式提问。

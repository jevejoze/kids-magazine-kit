# 封面（cover）

奇观特写 + 脑洞挑衅（颠覆日常经验的多巴胺刺激）。封面决定孩子要不要往下翻，是全期最重要的一页。

## 开工

1. 领任务单：`node scripts/pipeline.mjs ticket <issue> cover`，照单上的规则、参数、角色槽位写；最后一行的指纹写进 `_meta.ticket`
2. 读任务书（`child_question`、`topic_hint`、`weekday_theme`）、`data/profile.md`（兴趣权重）、最近几期的 `cover.json`（避免重复）
3. 写 `issue/cover.json`，字段见同目录 `schema.json`

```json
{
  "_meta": {"stage": "cover", "by": "", "at": "", "ticket": "<任务单指纹>"},
  "question": {"zh": "在挪威，为什么小学生<br>半夜一点还在踢足球？", "en": "Why are kids playing soccer at 1 a.m. in Norway?"},
  "answer": "答案要点：地球斜着转，夏天北极圈极昼全是白天，半夜太阳还在天上（今日一问照此讲）",
  "photo": {"url": "图片直链", "page": "图片所在页面", "author": "作者", "license": "CC BY-SA 4.0",
            "verified": "拍摄时间、地点从哪里核实的"},
  "photo_pos": "center",
  "stamp": "📸 00:44 · 挪威北角实拍",
  "asked_by": "",
  "strip": "",
  "crew": ["<asker>:happy:190", "<trickster>:smirk:150"],
  "crew_say": "半夜太阳还在打卡！",
  "credit": "© 作者 · 协议",
  "theme_icon": "🌍",
  "sources": ["核实问题答案用到的资料链接"]
}
```

`crew` 里写具体角色代号（任务单「角色槽位」查槽位由谁担），上面的 `<槽位>` 只是占位。

## 规则

- **选题定位（奇观特写 + 脑洞挑衅）**：
  - **严禁普通国家地理式风光**：平铺直叙的雪山、森林、日落、极光空镜等易陷入教科书感与审美疲劳，一律禁止；
  - **强制要求高反差视觉奇观**：必须是微观、深海、极限视角或不可思议瞬间的震撼奇观（如显微镜下的雪花结晶、正在吐泡泡的深海章鱼幼崽、高倍放大下的昆虫复眼、极低温下的物理奇景），带来颠覆日常经验的多巴胺刺激；
  - **强猎奇 + 社交货币（四层漏斗）**：拍得到奇观实景 ➜ 猜得到直觉陷阱 ➜ 讲得出一句话反转 ➜ 联想得到日常场景。优先选能成为孩子第二天去学校向同伴炫耀、打赌的话题，避免平淡或教条式的纯知识灌输。
- **主问题挑衅句式要求**：
  - **杜绝教科书式提问**：严禁使用“……形成机制是什么”、“……的原理”、“为什么会出现……”等说明文式问法；
  - **脑洞挑衅、反常识、反直觉**：必须将反常现象与孩子熟悉的日常经验（睡觉、踢足球、吃零食、比尺子等）强烈碰撞，引发认知冲突与打赌冲动；
  - **案例示范**：
    - ❌ “极昼形成机制是什么？” / “为什么北极夏天有极昼？”
    - ✅ “在挪威，为什么小学生半夜一点还在踢足球？”
    - ❌ “蜜蜂为什么筑六边形巢？”
    - ✅ “蜜蜂没学过数学，<br>为啥把格子造得比尺子还齐？”
  - **字数与断行**：问题 ≤ 24 字，太长可以用 `<br>` 在完整词组之间断行；数字和单位（如“十二点”“12 点”“2 吨”）不要拆开。
- **时令与节日联动（轻量点睛）**：遇到特殊节日（万圣节、愚人节等）时，封面选题优先从该节日的标志元素切入并做反常识奇观揭秘；角色可佩戴轻量节日道具（如万圣节南瓜帽），`stamp` 可标注节日特辑微标；点到即止，不破坏全刊常规周节奏，不做沉重特刊。
- 封面只放**一个问题**，留给孩子自己猜；答案由今日一问讲出来，要点写进 `answer` 给今日一问用（comic 的任务单把 `cover.question` 当上游值，问题一改，今日一问就要重做）。
- 照片一眼看懂、自带震撼与悬念。优先 Wikimedia Commons、NASA 等自由授权图库；数学、艺术题材用实物特写。
- 版式：顶部是刊名条，照片从刊名条下方开始、顶端渐隐进去；问题压在照片左下，角色在右下。所以照片的**主体要落在中上部**，下方留给文字。用 `photo_pos` 调裁剪（如 `"center 0%"` 显示照片最上面），塔顶、动物的眼睛这类关键部位要完整露出。
- 刊名条颜色自动取照片顶部的颜色；取出来不好看时用 `strip` 指定（CSS 颜色，如 `"#F6E7C8"`），否则留空。
- `stamp` 放在问题上方，和问题放在一起作为照片证据；只写核实过的信息（显微倍数、深度、拍摄时间或地点），≤ 14 字，不占照片中上部主体的位。
- `crew` 最多 2 个角色，表情和道具跟主题挂钩；按 spec 中的 150–200px 尺寸显示并靠近底边，角色列宽自适应；`crew_say` ≤ 12 字、单行显示。
- 孩子提出的问题被采用时，`asked_by` 写孩子的称呼，封面会用 💡 图标和奶油黄底色醒目显示"本期问题由 XX 提出"。

## 自检

`node scripts/pipeline.mjs check <issue>` 没有 `[cover]` 报错；答案能在 `sources` 里查到；照片协议允许使用；渲染后看一眼封面，主体没被刊名、问题、角色挡住。

# 策展记录

家长随时往"随手记"里丢一句话，不用管格式：哪页孩子看得最久、哪页跳过了、孩子最近在问什么、今天状态怎么样。
agent 每周日做一次策展，读这里、`feedback.jsonl`、`letters.md` 和 `MY_CHILD.md`，给出下周的调整建议；家长确认后才改。

对 agent 说：
- **"记一笔：……"**：追加到随手记
- **"做本周策展"**：出策展报告
